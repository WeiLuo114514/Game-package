# 开发日志 2026-08-31

## 今日改动

### 1. 随机流四拆（核心架构变更，GameData.gd）
- 原来单一 `_rng_state` 种子流，现按领域拆 4 条独立流，全部由 `_rng_seed` 确定性派生：
  | 流 | 状态变量 | 用途 | 调用方式 |
  |----|---------|------|---------|
  | 局内流 | `_rng_state` | 卡牌效果概率/抽洗/结算/Boss试炼/异彩判定 | `rng_randf/randi_range/shuffle` |
  | 事件流 | `_event_state` | 事件池选取/事件效果发放 | `event_randf/randi_range/shuffle` |
  | 商店流 | `_shop_state` | 商店货架/特价/盲盒/卡包内容 | `shop_randf/randi_range/shuffle` |
  | 表现流 | `_cosmetic_rng` | UID/盲盒花纹/夸夸 | `cosmetic_randi_range/randf_range` |
- `set_seed(s)` 盐值打散派生：`_event_state = _derive_stream_seed(s, 0x1E7A)`、`_shop_state = _derive_stream_seed(s, 0x50C2)`；base=0（随机局）自动时间回退（`_derive_stream_seed` 与 `_step` 均含 state==0 保护）
- **效果**：同一种子下局内怎么操作都不影响商店/事件/卡包内容（独立流纯函数），也防局内加随机导致商店货整体漂移

### 2. 残留旧随机函数名修复（18 个文件）
- 根因：上次 `randf→rng_randf` 改名只覆盖部分文件，effectScript/wildCardScript/magicScript 仍调用 `GameData.randf()/randi_range()` → 方法不存在返回 Variant → `:=` 类型推断报错（如 effect_4001.gd:14 `new_n` "Cannot infer the type"）
- 全部改名为 `rng_randf/rng_randi_range`，并把相关 `:=` 赋值改为 `=`（blind_box×4、shop_page×2、GameData 内部 chance/rng_shuffle/_roll 等）

### 3. 表现层随机审计（种子流只走机制）
- magic_copy_card.gd UID 生成 → `cosmetic_randi_range`（与 GameData `_random_uid_suffix` 一致）
- effect_5004 未洛夸夸（无游戏效果）→ `cosmetic_randi_range`
- blind_box.gd:410 盲盒花纹（纯视觉）→ `cosmetic_randi_range`

### 4. 存档按钮文本动态化（StartMenu.gd）
- `_refresh_archive_panels()` 末尾 `archive_btn.text = "存档 %d" % (GameData.active_slot + 1)`；`_init_harvest_setup` 连接信号后补调一次，进主菜单即显示正确栏位

## 关键设计决策
- 事件/商店拆两条独立流，而非并入一条"局外流"——用户明确要求，二者互不漂移
- 开局牌组抽取/Boss试炼/龙的财宝(5001)/预制魔法(5002) 归**局内流**（过关奖励本质是关卡进程内容）；若想也不受局内操作影响可再拆"奖励流"
- GDScript 方法遮蔽：Autoload 内部定义的同名方法优先于全局内置，外部脚本必须显式 `GameData.rng_xxx()`

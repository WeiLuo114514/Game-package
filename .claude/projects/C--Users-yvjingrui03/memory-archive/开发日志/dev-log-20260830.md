# 开发日志 2026-08-30

## 今日改动

### 1. 蓝色王牌 3007 潮涌 泛用化（effect_3007.gd + WildConfig.gd:234）
- 旧：仅弃置蓝色牌触发，费用+1，销毁概率 4% 起步每次 +4% 累积
- 新：任意颜色弃置都费用+1；销毁概率按弃置牌颜色固定——蓝 4%+8%=12%，其他 4%+12%=16%，不再累积
- 销毁语义：销毁潮涌自己（remove_wild_card(3007)），非弃置牌

### 2. 专属卡收藏环节（胜利后选一张收藏）
- **GameData**：`collected_deck` 从空壳变成完整持久化（`user://collected_deck.json`），新增 `add_to_collected_deck`、`load/save_collected_deck`、`_serialize_collected_card`/`_deserialize_collected_card`（保存卡牌全部 17 个维度字段）
- **ending_page.gd**：`_on_return_pressed` 分流——胜利(`_is_victory`)且有专属卡(`has_tag(EXCLUSIVE)`)→ `_enter_collocation()` 播 `"NewCollocation"` 动画进收藏；无则直接 `_finish_return()`
- **收藏交互**：点 HBoxContainer 卡槽 → 卡消失上预览位 `NewCollocation/Card`；点另一张 → 替换（旧卡回列表）；**next 按钮信号统一入口** `_on_return_pressed→_handle_next`——结算环节进收藏 / 收藏环节已选卡则确认收藏并退出 / 未选卡等待 / 否则直接返回。不新建 confirm_button，复用 next（用户已在编辑器接线，连接仍指向 `_on_return_pressed`）

### 3. select_card.gd 修复（专属魔法报错）
- 根因：重构 card_container 后 SelectCard/CardContainer 的 `description_page` export 留空（nil），select_card.gd 两处直接 `card_container.description_page.visible` 崩溃
- 修复：删除两处该引用（select_card 自己的 `description_page` export 指向同一节点已覆盖），无逻辑损失

### 4. wins/uses 统计规则改造（GameData + PlayField + ActiveCardContainer）
- **账本 key 化**：`card_ledger` 的 key 从 `card_id`(int) → `"{id}|{name}"`(String)；`load_card_ledger` 自动迁移旧 int key → `"id|"`（先收集再改，避免遍历时改字典崩溃）
- **uses 新规则**：`run_card_uses` 本关收集，打点于主动弃置(`ActiveCardContainer._discard_to_fold`) + 结算从牌位收回(`PlayField._fly_out_cards_and_clear_slots`)，`flush_level_to_ledger` 每关合并进账本（不再用结算队列 stats.card_usage）
- **wins 新规则**：移出 flush，新增 `apply_run_wins_to_ledger`，整局胜利(`ending_type==VICTORY`)时遍历 draw_pile——普通卡按 (id,name) 去重 +1；专属卡按随机 uid 每张 +1；`exclusive_ids`(card_id集合) 排除原归属运算牌
- **uid 兜底**：`_card_ledger_key(cd)` 统一索引——专属卡用 `(card_id, card_uid)`（X-xxxx 随机唯一，同效果同名的专属卡不合并），普通卡用 `(card_id, custom_name)`；`get_card_ledger_for(cd)` 按对象查战绩，DigitalPanel 改用它
- flush_level_to_ledger 不再每关加 wins，is_win 参数已删

## 关键设计决策
- 收藏**不查重**，直接 append（每张专属卡 uid 唯一 X-xxxx，card_id 只是效果脚本标记）
- 收藏卡**留在 draw_pile**（draw_pile 下局被新卡组替代，收藏走独立 collected_deck 持久化）
- 「携带入局」（后续游戏开始从 collected_deck 带卡）**未实现**，本次只做持久化基础，反序列化函数已留好

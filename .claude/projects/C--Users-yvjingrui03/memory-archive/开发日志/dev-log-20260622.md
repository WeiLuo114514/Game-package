## 王牌双层卡面 hover 动画

**涉及文件**: `WildCardUI.gd`, `WildCard.tscn`, `goods_wild_card.gd`, `goods_pack.gd`, `goods_magic.gd`

- WildCardUI 新增 `top_card_texture` / `bottom_card_texture` 两个 TextureRect（场景节点：TopTextureRect / BottomTextureRect）
- hover 进入时：卡片整体 scale 1.0→1.1 + 几何层 scale 0.55→1.0 + alpha 0→1，三属性并行 0.2s cubic ease-out
- hover 离开时：强制归位几何层（a=1, scale=1），卡片缩回 1.0
- 纹理加载约定：`res://资源/Picture/WildCard/{id}B.png`（背景层）/ `{id}T.png`（几何层），不存在则回退单纹理
- 27张常规王牌分层材质已放入该目录（`*B.png` + `*T.png`）
- 商店三件商品统一 hover 弹跳：goods_wild_card（双层动画）/ goods_pack（纯缩放）/ goods_magic（纯缩放）

**Why:** 用户在 PS 里把卡面分成上下两层绘制，hover 时背景先放大、几何层再渐显，产生双层动感。

### 技术规范
- 信号驱动架构：GameManager 发射 17 个信号，UI/enemy/棋盘/结算各自订阅
- 伤害公式：除法公式 `damage × 3 / (3 + DEF)`，DEF_K=3
- 行动消耗：`max(0.5, snapped(敌速/我速, 0.1))`，浮点数精确到小数点后一位
- 衰减系统：电护盾/风buff/水debuff 每回合 ×0.7，<1 时归零

# 开发日志 2026-09-08

## 今日改动（多会话收尾，均未逐项跑 Godot 验证）

### 1. 存档持久化修复（核心，GameData.gd）
- **现象**：打完一局进度不落盘；实测 `%APPDATA%/Godot/app_userdata/Arithmetrick/` 只有 8/30 旧文件躺在根目录、`slot_0/` 目录根本不存在。
- **根因**：三栏存档(slot)化把路径改成 `user://slot_N/`，却从没建目录。**Godot `FileAccess.open(WRITE)` 不会自动建父目录** → open 返回 null、代码静默 return；`load_*` 的 `file_exists` 也因目录缺失 false 直接跳过。双重静默失败。
- **修复**：`_ensure_slot_storage()` 建当前槽目录 + 把旧版根目录 history/ledger/collected 一次性迁移进槽位（写成功才删旧档）；`_ready`（load_active_slot 之后）与 `switch_slot` 各调用。

### 2. 弃牌经济解耦 + 折損异彩重做（ActiveCardContainer/GameData/CardUI/MagicConfig）
- 用户报费用 bug：剩余费用 0 但弃牌要 1 费时，折損牌弃置仍被放行且费变成 1（-1 被 clamp、折損 +1 生效）。
- **重做**：折損 = 免费弃置——拖拽时弃牌区显示「免费」；**不扣费、不返还、不推高后续弃牌费用阶梯、不耗免费弃牌次数**，但计次与弃牌触发器照常。
- **实现**：弃牌费用阶梯独立计数 `fold_fee_discard_count`（与计次 `discard_count_this_turn` 解耦）；`_is_free_discard()` 判折損激活态；`_update_fold_cost_label()` 免费/次数/费用三态；`_discard_to_fold()` 免费分支无条件放行。副产物：逐客令/吹又生多计次不再抬弃牌费用（只喂计次类效果）。
- desc 同步 CardUI/折損魔法/CLAUDE.md/经济平衡/游戏设计文档。

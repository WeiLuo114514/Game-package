# 开发日志 2026-07-15

## 系统开发

### 结局面板完善
- `capture_ending_snapshot` 改为从 `global_stats` 读取全局累计数据（总得分/总卡牌使用/总弃牌/全局MVP卡牌）
- `global_stats` 新增 `total_score` 和 `total_discard` 两个字段，`commit_stats_to_global` 同步累加
- 标签改为带说明文字的格式：「总得分：999」「使用运算牌：999」「最佳得分：999」
- MVP 卡牌从 `global_stats.card_usage`（跨局累计）中选取，非仅本局
- 顺序调整：`commit_stats_to_global` 先于 `capture_ending_snapshot` 执行，确保快照拿到最新全局数据

### SettlementSequencer 超时假阳性修复
- **根因**：`play_phase_requests()` 的 5 秒定时器在空阶段也创建，函数返回后定时器继续倒计时，5 秒后触发假阳性 warning
- **修复**：`_active.is_empty()` 提前 return（不创建定时器）+ `_phase_completed` 标志位（正常完成的阶段静默返回）

### 事件系统
- 事件 5「路边的修行者」：三个选项加上金币消耗（15$/10$/20$），新增免费选项「简单练一练」（生效槽位+1）
- PAY_MONEY 放在 effects 数组首位，余额不足时阻断后续效果

### 复制魔法修复
- `magic_copy_card.gd`：`applied_magic_ids = []` → `.clear()`，Godot 4.7 对 Resource duplicate 后的 typed array 赋值校验失败

### 红色王牌 1008 群众路线重做
- 旧：场上每有 1 张运算牌初始底数 +3
- 新：每张运算牌 +1，红色额外 +1（红牌 2 点/张 vs 其他 1 点/张）

## 王牌效果节点重构

**核心变更**：WildEffect 节点不再由 GameData 全局缓存管理，改为直接挂在 WildCardUI 场景的 EffectNode 子节点上。

- `BaseWildEffect.gd`：`extends Node` → `extends Node2D`，所有王牌效果自带 `global_position`
- `GameData`：删除 `_wild_effect_cache` 和 `_get_effect_instance()`，新增 `_make_temp_effect_instance()`（仅关卡王牌用）
- `trigger_wild_effects()`：改为遍历 `WildSlot.wild_card_nodes` 拿 `effect_node`
- `WildCardUI._try_load_effect()`：直接用场景的 EffectNode 加载专属脚本 + 注入 `wild_data`/`trigger_list`
- 删除 `bind_effect()`
- PlayField/WildSlot 中所有 `_get_effect_instance` + `bind_effect` 调用改为直接访问 `node.effect_node`

**运算牌效果**：OPCard 场景已有 EffectNode，代码在 `op_card.gd` 的 `_refresh_game_effect_ui()` 里直接 `set_script` + `init_with_card`，无需改动。

## 飘字位置统一

- `GameData.show_tip()`：新增 `tip_pos: Vector2 = Vector2.INF` 参数，`Vector2.INF` 哨兵回退鼠标
- `GameData.chance()` / `_show_chance_tip()`：同上，`Vector2.INF` 替代 `Vector2.ZERO` 防原点误判
- 运算牌效果：`chance()` 第三个参数用 `global_position`（自身 EffectNode）
- 王牌效果：`chance()` 和 `show_tip()` 用 `global_position`（自身 EffectNode）
- PlayField 王牌生效飘字：`show_tip(w_cfg[0], w_color_key, wild_node.global_position)`

## 技术教训

- **`_context.get("card")` vs `card_data`**：`ON_DISCARD_CARD` 等触发器通过 `trigger_wild_effects` 传递的是 `card_data`（CardData），不是 `card`（Card 节点）。王牌效果中必须用 `card_data`
- **`ON_SHUFFLE_IN` 从未 dispatch**：触发器定义在 TriggerDefines 但对应的 dispatch 代码缺失，需要在 `_process_enter_draw_pile()` 中补充
- **Resource 的 `@export var tags: Array[int]`** 不能直接赋值 Array，需用 `clear()` + `add_tag()`
- **`Vector2.ZERO` 做哨兵不可靠**：用 `Vector2.INF` 替代
- **`_is_animating` 必须成对设置+重置**：每个分支 exit 前都要 `_is_animating = false`
- **`_can_trigger` 不给手牌区漏判**：合伙人等需要在槽位才生效的效果，加 `active_zone_index >= 0` 守卫

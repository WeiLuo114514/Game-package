## 2026-07-09 凌晨 — 音效系统

### AudioConfig 重构
- 单文件映射 `sfx_mapping` + 音频集 `sfx_sets`（类似 UE SoundCue Random 节点）
- `AudioManager.play_sfx_set(key)` — 从集合随机选一播放
- `AudioManager.play_sfx_set_multi(key, count)` — 随机选 N 个连续播放

### 代码接入点
- **放牌**：`op_card._state_drag_enter()` → `card_pickup`
- **拿牌**：`op_card._state_slot_enter()` → `card_place`
- **抽牌**：`GameData.draw_cards()` 实际抽到牌后 → `card_draw`
- **金币**：`InfoBoard.update_info()` 检测 `delta = target - _displayed_money`，delta≥15 播 `coin_large`，否则随机播 `coin` 1~3 次
- 金币音效写在 UI 层（非数据层），一处覆盖全项目 18 个 `player_money +=` 调用点

### AudioConfig 当前状态：已清空
所有 `load()` 调用已删除，等待逐个添加 AI 生成的音效文件后注册。
`sfx_mapping`、`sfx_sets`、`bgm_mapping` 三表保留结构为空。

### 文件变更
- `AudioConfig.gd`：清空后仅保留结构
- `AudioManager.gd`：新增 `sfx_sets` 引用 + `play_sfx_set()` + `play_sfx_set_multi()`
- `info_board.gd`：`_play_coin_sfx()` 检测收入 delta 自动播放
- `op_card.gd`：拖拽/入槽音效
- `GameData.gd`：抽牌音效

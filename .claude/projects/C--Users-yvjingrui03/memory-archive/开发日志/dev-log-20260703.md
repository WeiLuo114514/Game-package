## 技术教训
- **永远不要用文本编辑 .tscn 文件** — 手动在 Godot 编辑器中改
- **Sed 的 `\t` 在 shell herestring 中会被解释为字面量 `t`**，需要用 `$'\t'` 或 Python
- **Python 替换大文件时注意 `c[:old_start-1]` 会切掉邻接内容**
- **`class_name` 循环引用**用 `Node`/`Control` 基类规避
- **GDScript const 数组不能用枚举简写**，用裸数值
- **effect 节点不在场景树，`_ready()` 不调用**，用 `_init()` 或首次 `_can_trigger`

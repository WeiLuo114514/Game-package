## 标签系统扩展

- **【永恒】ETERNAL=32**：删牌魔法(20001)无法选中带此标签的卡。`card_container.gd` 过滤 + `magic_delete_card.gd` 纵深防御
- **【变色龙】CHAMELEON=64**：`has_color()` 对任意颜色判定返回 true。全项目唯一颜色入口，一处修改全局生效
- **【超体】SUPERBODY=128**：卡牌等级固定为 3 级。通过 `get_effective_level()` 方法实现（非 getter/setter，避免 Godot 资源初始化字段偏移 bug）

### 超体实现的教训

最初用 `@export var level` 的 setter/getter 实现，但在 Godot 4 中 `CardData.new()` 时会用 int 默认值 0 调 setter，把 `_base_level` 从 1 冲成 0，且内部属性表偏移导致所有 @export 字段错位。最终方案：`level` 保持简单 `:= 1`，新增 `get_effective_level()` 方法，所有需要等级判定的地方（CardUI、op_card、GameData、select_card、card_container、31 个效果脚本）统一改用此方法。

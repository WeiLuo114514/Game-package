## 新增卡牌

### 关卡王牌 L1022 斗转星移
- 品质 2，ON_PRE_SETTLE，stage_mods: `swap_slot_1_and_n`
- MATH_REVEAL 阶段交换 1 号位与 N 号位（`_perform_settlement_swap`）

## 新系统

- `LoreConfig.gd`：`card_lore` 字典，53 张卡均有风味文字

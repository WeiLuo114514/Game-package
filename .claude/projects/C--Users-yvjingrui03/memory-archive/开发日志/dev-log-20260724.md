# 开发日志 2026-07-24

## 畅游二面（业务面，王沛乐，约 55 分钟）

### 面试官
王沛乐，疑似主策或资深策划，水平专业，提问深入且耐心教学。

### 核心问答
- 三消 vs 二合体验差异：三消看脸/单局离散/需局外系统兜底，二合成就感强但爽感平淡/适合长线沉浸
- 产销循环：笔试作业推得不够清晰，面试官指出单机与网游在数值设计上的底层逻辑鸿沟
- AI 工作流：人脑定架构+AI 做填充+测试-评估-回滚闭环+Markdown 归档
- 排行榜设计：从玩家攀比心理出发→多维榜单扩大上榜面→服务端校验/防作弊。被追问服务端架构时坦承未实现
- 红海/蓝海赛道策略：红海需渗透竞品+低成本买量，蓝海需求与用户盘子不清晰
- 职业规划：明确策划方向（数值+玩法），不做纯程序
- 岗位确认：重庆长期实习，全球化跨平台休闲游戏（非 MMO），团队已全面 AI 化

### 表现好的点
- AI 工作流回答有体系有细节，与团队 AI 化方向高度契合
- 三消二合对比精准，笔试三款游戏真玩了才有的判断
- 抽象问题卡住时切具体案例（用元素爬塔行动点系统讲功能落地流程）
- 主动示弱但每次后面跟了在做的补救（AI 拉表/蒙特卡洛验证）
- 最后坦诚「擅长卡牌不擅长 MMO」，面试官随即澄清团队方向，说明他在帮忙找匹配点

### 暴露的短板
- 产销循环/商业化思维——单机视角，缺乏 F2P 实践
- 服务端架构认知——排行榜追问暴露纯客户端思维
- 两个评价：面试官直言「缺乏商业化思维」「单机与网游存在本质差异」

### 关键经验总结
1. **应试心态调整**：被问没接触过的概念时，先承认边界再尽力推演，比硬答更可信
2. **抽象→具体的切换**：当抽象框架答不出来时，直接举具体项目例子反推回框架。元素爬塔行动点系统这个案例救了功能落地流程那一题
3. **主动示弱+跟补救**：三次主动说不会，但每次后面接「我在用 XX 方式补」，效果远好于死扛或纯认错
4. **面试官教学=好信号**：他花了 4+ 分钟讲商业化逻辑，是觉得你可培养，不是嫌你差
5. **最后一段要桥梁**：坦诚不擅长的同时表达想学，让对方有机会澄清岗位方向来匹配你

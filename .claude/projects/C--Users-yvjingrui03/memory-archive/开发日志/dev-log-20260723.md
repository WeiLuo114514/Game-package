## 行动点系统代码审查

审查了元素爬塔 GameManager.gd 和 UI.gd，验证了两个维度是正确分离的：

| 维度 | 变量 | 影响 | 改变行动条？ |
|------|------|------|:--:|
| 行动值上限 | `max_action_points` (装备SPD) | 每回合操作次数上限 | 是 |
| 速度 | `_player_spd_buff` / `_enemy_spd_debuff` (风/水) | 每次操作消耗 | 否 |

- 装备 SPD → `max_action_points += spd` → `action_points_changed` → `energy_bar.max_value` 变化
- 风加速/水减速 → 只改 `_player_spd_buff` / `_enemy_spd_debuff` → 只发射 `speed_stats_changed` → 不碰 `max_action_points`
- `player_spd` 基础速度始终为 5，装备不修改它
- 命名瑕疵：装备字段叫 `spd` 但实际是「行动值上限加成」而非加速度

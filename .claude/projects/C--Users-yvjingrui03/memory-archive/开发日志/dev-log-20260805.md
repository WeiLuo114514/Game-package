# 开发日志 2026-08-05

## 卡牌阴影方向修复

卡牌越靠近屏幕边缘时阴影偏移方向反转：原来向外偏移（点状光源在屏幕后方的效果），改为向内偏移（平行光从正上方照射，卡片悬浮在平面上方），对齐小丑牌视觉。

**修改文件**：
- `op_card.gd:184-185` — `delta_pos * coeff` → `-delta_pos * coeff`
- `ShowCard.gd:103-104` — 同上

## 事件牌池数据 Bug 修复

`EventConfig.event_card_pool` 引用的 ID 101-103 不存在，实际事件牌数据在 110-112。修复为 `[110, 111, 112]`。

事件牌暂不接入商店（用户决定仅保留里程碑节点触发）。

## 试炼王牌跨单元加载 Bug 修复

**根因**：`generate_boss_trial()` 仅在 `advance_level()` 中当实际到达 Boss 关（`level % 3 == 0`）时才调用。进入新单元时 InfoPage 立即展示三关面板，Boss 面板读取 `_boss_trial_id` 得到的是上一单元的旧值。

**修复** (`GameData.gd:293-298`)：将试炼牌生成时机从「到达 Boss 关」提前到「进入新单元第一关」（`level % 3 == 1` → `generate_boss_trial(level + 2)`），InfoPage 渲染时 `_boss_trial_id` 已就绪。

### 关键设计决策

- **9015 傲慢**：从 RNG 方案（50%概率×每张牌）改为确定性效果（N号位轮转底数翻倍），消除方差问题
- **9017 暴怒**：动态惩罚——触发时当场涨目标分，而非开局预扣。因果链对玩家透明
- **9010 弃牌税**：加抽牌补偿，避免唯一纯负面试炼牌
- **9011 量子纠缠**：加 50% 目标分代价，从无存在感提升到有意义的权衡

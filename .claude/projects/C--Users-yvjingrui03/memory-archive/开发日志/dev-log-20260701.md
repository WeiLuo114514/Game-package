## 黄色运算牌重做（17 张全部注入概率）

旧版黄牌全是确定性效果 → 重做为每张卡带概率维度（chance()+prob_bonus）。春风→金风玉露（衰减链变号）、麦浪→千术（概率变×）、废料→资金运作（概率增幅器）、均匀→老虎机（离散奖池）、支撑→押注（黄牌数驱动概率）、庄家通吃→谢谢惠顾（概率货币+邻位重结算）、新增上帝之手（好运数变现）。

**Why**：建立黄色流派认知锚点——「每张牌都是一次小抽奖」。概率线（白手起家/签订契约/金黄扑满/豪赌）、货币线（利息/刮刮乐/兑换/奇货可居）、底数线（大丰收/豪赌）三条线在王牌层交汇。

**How to apply**：所有黄牌效果脚本在 `effectScript/yellow/` 下，CardConfig 20001-20017。`GameData.chance(pct, card_name)` 第二个参数为卡名时自动弹金色飘字。

## 底数公式正式确立

公式 `display = floori((base_number + turn_base_delta) × turn_base_mult)`，计算顺序**先加后乘**。

术语规范：
- **「翻倍」**：操作 `turn_base_mult *= N`，乘算通道，放大全部已累积 delta
- **「底数+N」**：操作 `turn_base_delta += N`，加算通道
- 两者不等价，翻倍收益更高，是设计而非 bug

详见 [[base-number-formula-20260704]]

## WildCardUI 描述拉取模式

- `_on_mouse_entered()` 中调 `refresh_description()` → 从 `effect_node.get_current_description()` → `wild_data.data` 拉最新计数
- `wild_state_changed` 信号在效果修改状态后推送，触发 `refresh_description`（结算中 mouse_lock>=2 时仍有效）
- `bind_effect()` 自动连接 `wild_state_changed` → `refresh_description`

## 技术要点

- `get_display_base_number()` 包含 `(base + delta) * mult`，不可直接加到 `turn_base_delta`
- `_can_trigger` 不应有副作用（tip 等），保持纯检查
- `ON_DISCARD_CARD` 的 context 需包含 `card_data`（通过 `on_discard_occurred` 可选参数传入）
- `wild_state_changed` 必须在 `wild_data.data` 写入后、任何 `_execute` return 前发射

# 开发日志 2026-08-11

## 设置页面全量实现

### 架构拆分
- `CanvasLayer/Setting` → `settingMenu.gd`：页面跳转动画（Menu ↔ ExitConfirm ↔ Setting TabContainer）
- `CanvasLayer/Setting/Setting` → `setting.gd`：设置控件接线 + ConfigFile 持久化

### 页面跳转系统（七动画）
| 动画 | 触发 | 效果 |
|------|------|------|
| `into` | 打开设置 | Menu 从下方滑入 |
| `setting` | 点「设置」按钮 | Menu 滑出，TabContainer 滑入 |
| `setting_to_menu` | 设置页点返回 | 反向，回到 Menu |
| `main_menu` | 点「返回主页面」 | ExitConfirm 确认框滑入 |
| `main_menu_to_menu` | 取消返回 | 确认框消失 |
| `out` | 确认/关闭 | 模糊渐消 + hide + emit closed |
| `RESET` | 初始化 | 默认值 |

- 返回主菜单确认时区分「关闭」和「切回主菜单」：`_return_to_menu` 标志位，`out` 动画结束后调用 `game_world.change_screen("StartMenu")`
- `closed` 信号连接 `GameWorld.close_settings()`

### 设置内容实现（6 项）
- **主音量/BGM/音效**：三个 HSlider，`bind()` 复用同一回调 `_on_volume_changed(bus, label, key)`
- **语言切换**：OptionButton → `TranslationServer.set_locale()`，zh_CN/zh_TW/en
- **屏幕震动**：TextureButton toggle → `GameData.screen_shake_enabled`
- **显示模式**：OptionButton → `DisplayServer.window_set_mode/flags`，窗口/无边窗口/全屏

### 持久化（`user://settings.cfg`）
- `setting.gd` 独立 ConfigFile，与游戏存档分离（存档后续用 `user://save.cfg`）
- `AudioManager._ready()` → `_load_volume_settings()` 启动时恢复音量
- `GameWorld._ready()` → `_apply_display_mode_on_startup()` 启动时恢复显示模式
- `set_volume()` 加 `clampf(v, 0.001, 1.0)` 防 `linear_to_db(0)` 爆 -inf

## Bug 修复

### 教程 SETTLE 阶段动画不播放
- `_enter_step(Step.SETTLE)` 的 match 分支缺失，前一步 step2 动画一直循环
- 补 `Step.SETTLE: _play_anim("step3")`，引导箭头指向结算按钮

### RoundMenu 子页面残留
- 从事件页返回主菜单再开新局，事件页仍然显示
- 根因：`_ready()` 只执行一次，RoundMenu 隐藏再显示时 `now_screen` 和子页面 visible 状态保留上一局的值
- 修复：`_enter_round_menu()` 入口加 `_reset_to_info()`，所有子页面关闭 + info 亮起 + now_screen 归位

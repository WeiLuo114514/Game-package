## 古战场遗迹重做（Lv9 事件 6）

旧版三个选项（先锋战旗/军备仓库/不朽意志）过于强力（同时加槽位+回合/手牌+费用/回合+费用），替换为：

|------|------|------|
| 华贵的羽袍 | 利息上限 5→10$ | `interest_cap += 5` |
| 磨损的腰包 | 魔法容量 3→4 | `max_owned_magics += 1` |
| 折断的魔杖 | 手牌上限 6→7 | `INCREASE_HAND`（复用已有） |

## 两个新 EventEffect

### INCREASE_INTEREST_CAP（利息上限+N）
- `interest_cap` 默认 5（原硬编码在 `game_settlement_info.gd:60`）
- 选择华贵的羽袍 → `interest_cap += 5` → 变为 10
- 利息公式：`mini(floori(money/5), GameData.interest_cap)` — 每 5$ 得 1 利息，上限动态

### INCREASE_MAGIC_CAP（魔法数量上限+N）
- `max_owned_magics` 从 `const` 改为 `var`（默认仍为 3）
- 选择磨损的腰包 → `max_owned_magics += 1` → 变为 4
- 所有魔法容量检查（`can_hold_magic()`/`buy_magic()`/`acquire_magic()`）自动适配新变量
- 外部引用更新：`blind_box.gd`、`debug.gd` 中 `MAX_OWNED_MAGICS` → `max_owned_magics`

## 结局面板设计与规划

### 现状审计
- `GameData.endless_mode` 和 `GameData.trigger_game_ending` 两个 flag 已声明，被 Lv18 事件设置，但**从未被任何代码检测**
- 无 EndingPage 场景/脚本
- Lv18 事件完成后直接进入商店→InfoPage，玩家点击「下一把」进入不存在的 Level 19

### 架构决策
- **EndingPage 放 CanvasLayer 而非 RoundMenu**：和 SelectCard 同级，作为全屏覆盖层；不受 RoundMenu 页面切换动画影响；语义明确（终点而非中转站）
- **分支结局**：两个分支（归途/征程再续）均终止游戏返回 StartMenu，差异仅为叙事文本

### 计划（详见 `idempotent-singing-blanket` plan 文件）
1. 新建 `EndingPage.tscn` + `ending_page.gd`
2. GameData 新增 `EndingType` 枚举 + `ending_type` 变量
3. `event_page.gd` 两个 exec 函数加设 `ending_type`
4. `RoundMenu.gd` 在 `_on_event_completed()` 开头检测 `ending_type > 0`，路由到 EndingPage
5. `GameWorld.tscn` CanvasLayer 下添加 EndingPage 实例

### 设计讨论：仅 Boss 回合用尽失败
讨论了「所有关卡回合用尽即死 vs 仅 Boss 关即死」，结论保持现状（仅 Boss 关即死）。理由：
- 经济落后本身就是慢性惩罚（0 奖励 + 0 利息 + 没盲盒 → 下关更难过）
- 让玩家多活几关体验「上次贪便宜的后果」比直接掐断有深度
- 收紧方向应优先考虑缩短回合数或提高 Boss 门槛，而非扩大小失败惩罚

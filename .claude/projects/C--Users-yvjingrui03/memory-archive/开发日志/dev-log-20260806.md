# 开发日志 2026-08-06

## 动态起始牌组系统设计

参考怪物火车的氏族起始牌机制，决定将固定 10 张起始牌改为「固定核心 + 随机池抽取」。

**最终方案**：
- 固定核心 7 张（4 纯运算 + 1 底牌专属声明牌 + 2 待定）
- 随机池抽 3 张（分色池，各色在本家内部随机）
- 起始随机牌用独立新场景展示（不复用 DrawCardPage，避免「选择」隐喻污染）
- 重随功能留到 meta 解锁（收藏进度奖励）
- 底牌系统整体作为后续更新内容出现，池子系统先做最小可用版本

## 卡牌效果重做

### 10012 爆燃
- 运算符：+ → ×，底数：2 → 1，费用：1 → 3
- 效果：`turn_base_mult *= 2` 每层 → `turn_base_delta += bonus × 层数`（L1=2, L2=3）
- 从指数翻倍变为线性成长

### 10011 传火
- 新增自身 buff：`turn_base_delta += bonus`（L1=2, L2=3）
- `apply()` 改为始终返回 true（自身 buff 必定生效）
- `get_affected_indices` 新增自身索引

### 20017 上帝之手
- 「本回合」→「本局」，用 `GameData.lucky_count` 累积计数
- 删除 snapshot/`on_effect_triggered`/`submit_animation_request`（旧逻辑 delta 永远为 0，是 bug）
- 简化为 `turn_base_delta += per_success × lucky_count`，无成功时返回 false

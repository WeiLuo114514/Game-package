# 开发日志 2026-08-04

## 灵言削弱 (30001)

**设计意图**：灵言原来的效果太强（被弃置时免费变×），增加费用消耗作为削弱。

**最终方案**：
- Lv1：最左侧 1 张手牌运算符变为×，消耗 2 点玩家费用
- Lv2：最左侧 2 张手牌运算符变为×，消耗 1 点玩家费用
- 消耗方式：`GameData.stat.cost.max -= cost_drain` + `battle_info_changed.emit()`

**关键认知对齐**：费用（`stat.cost`）≠ 货币（`player_money`）。费用是每回合放置卡牌的战场资源池，货币是局内商店消费用。

**涉及文件**：`effectScript/blue/灵言.gd`、`代码/配置/CardConfig.gd`

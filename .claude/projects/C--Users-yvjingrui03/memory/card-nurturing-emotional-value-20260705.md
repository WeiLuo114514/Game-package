本作区别于传统 Roguelike DBG 的一个重要维度：**卡牌会跟着玩家成长**。

**Why**：2026-07-05 讨论中确认——在杀戮尖塔每局 build 清零，但在本作中永久牌库 + 魔法印记DIY + 卡牌UID共同构成了玩家对牌组的「所有权和依恋感」。这是 Roguelike 缺乏但养成类游戏擅长的事。

**How to apply**：
- 设计新系统时优先考虑「如何让玩家对单张卡产生感情」而非仅关注机械平衡
- 魔法印记、专属标签、自定义命名不是边角功能，而是核心体验的一部分
- 删牌、升级、贴魔法的每个决策都在强化玩家的「这是我的牌」的感觉
- 未来卡牌故事/回忆录/收藏柜/转生系统都可沿此方向扩展

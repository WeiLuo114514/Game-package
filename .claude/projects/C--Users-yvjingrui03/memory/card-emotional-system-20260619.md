2026-06-19，从标签系统延伸讨论成长出的完整「卡牌情感化」系统设计。

**Why**：用户从实体卡包的「把玩感」出发，希望数字卡牌也能建立玩家与单张卡牌之间的独特情感连接——「这张卡是我的」。传统 DBG 的 meta 奖励是解锁新卡牌（横向扩展），本系统是**把经历凝固成收藏品**（纵向深化）。

**How to apply**：以下全部为设计定稿，均未实现。开发时以此为规范。涉及 CardData 结构变更、商店系统扩展、新 UI 页面（回忆录/收藏柜）。

## 1. 卡牌 ID 系统

每张卡牌在进入牌堆时生成唯一 ID，格式：`品质-5位随机码`

- 例：`S-7K3A9` / `A-2M8F1` / `B-X4399` / `C-9P2L5`
- 随机码使用 hash 前几位（大写字母+数字混合，非纯数字），保证唯一性
- **位置**：卡牌右下角，小黑框内，等宽字体，小号，低对比度灰度
- **视觉**：战斗中像刻印安静待在角落，收藏柜中放大展示
- **品质等级**：S / A / B / C，系统在卡牌生成时判定
- 品质前缀替代了独立的「品质标签」——品质信息仍在，但不是「评价」，是「编号的一部分」

## 2. X 品质 —— 玩家专属标记

玩家使用**专属魔法（改名魔法）**后，ID 的品质前缀变为 `X-`，后缀（随机码）不变。

- `S-7K3A9` → `X-7K3A9`
- `B-X4399` → `X-X4399`

**设计含义**：X 不是「更好」或「更差」，是「退出品质评价体系」。
- X = 未知 / 可变 / 玩家专属（宝可梦 X 神、万智牌 X 费用、XBRL extensible）
- S/B/C 是系统的分类，X 是玩家的宣言：「我不在这个坐标系里」
- 后缀保留 = 编号终身不变，卡牌可追溯

**X 卡牌额外追踪数据**：
- 被使用的总次数
- 被加入收藏的日期和时间
- 原品质（改名前的 S/A/B/C，用于回忆录追溯）

## 3. 专属魔法 0$（改名魔法）

**获取方式**：
- Boss 战胜后，商店固定出现一个 0$ 专属魔法（必得）
- 普通盲注（Small/Medium）下，每次刷新商店低概率随机刷出

**效果**：
- 对牌库中一张卡牌使用
- 可修改卡牌名称（自定义）
- 自动触发 X 品质转换
- 改名后卡牌保留原卡名的小字标注（防止后期认不出）

**设计要点**：
- 0$ 是关键——情感行为不应该是「划算」的，它是系统递过来的笔
- Boss 战后出现时机：玩家情绪最高点，刚经历考验，此时签名最有仪式感
- 这是一次性消耗品，稀有度本身让改名行为成为一件大事

## 4. 胜利收藏 & 回忆录（Memorial）

### 胜利时
- X 卡牌仅在**游戏完全胜利**（通关全部 18 关）时永久进入玩家的**收藏柜（Collection）**
- 收藏柜是独立 UI 页面，展示所有收藏卡牌：变种、ID、曾用名、使用次数、加入日期

### 失败时
- X 卡牌不进入收藏，但进入**回忆录（Memorial）**
- 回忆录记录：卡名、ID、变种、失败日期、倒在哪个 BOSS
- 回忆录只读，可浏览、可翻页、可截图
- 回忆录中的卡**不能**在游戏中使用

**设计哲学**：
- 胜利收藏 = 活着的战友，回来了
- 回忆录 = 没能活着回来的战友，但没有被遗忘
- 墓碑不解决「带不出来」的问题，但解决「消失得无影无踪」的问题

## 5. X 卡牌在未来商店出现

X 卡牌进入收藏后，会在后续 run 的商店卡包中出现：

- **不替换**现有卡包产出，而是**额外多出一个卡牌选项**
- 叙事：「你的专属卡牌来找你了」
- 每次商店**只能选一张** X 卡牌（防止泛滥）
- **冷却机制**：同一张 X 卡在连续两局中不会再次出现（防止惊喜变骚扰）
- X 卡牌在商店中仅作为纯外观皮肤使用（不带变种数值效果），保持平衡

## 6. 变种系统 —— 确认单一变种

变种每张卡只能有一个，是卡牌的「核心身份」和主要视觉表现（边框、粒子、卡背纹理）。多变种叠加不做。

**为何不变种叠加**：
- 策略深度主要来自抓牌不确定性、路线选择、卡牌配合、敌人机制
- 单一变种模拟了实体抽卡的稀缺感和确定性——「一张卡就是一张卡」
- 与 X 品质形成「身份 + 经历」的双层结构：变种是出身，X 是归属

## 7. 系统特点总结

本游戏三大标签：**DBG + Roguelike + 收藏（Collection）**

传统 DBG 的 meta 奖励是解锁新东西（横向），收藏系统是把经历凝固成纪念品（纵向）。这比解锁新卡更有情感重量——解锁是「系统给我的」，收藏是「我赢回来的」。

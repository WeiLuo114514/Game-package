# 米哈游策划大赛参赛构想（2026-07-10）

## 基本信息

- **比赛**：米哈游第二届游戏策划大赛（预计 2025 年底 ~ 2026 年初寒假）
- **要求**：3D 游戏，必须有 3C（角色、摄像机、操控），包含交互/关卡/战斗
- **人数**：1-3 人
- **引擎**：Unity 为主（Godot 3D 也可，但评委更熟悉 Unity）
- **一等奖**：5 万 / 等值黄金
- **附加价值**：进复试可直面原神/星铁/绝区零制作人，可能直接拿 offer

## 参赛构想：「时间追捕」

### 核心机制（只有两个）
- **冲刺**：短距瞬移，有 CD，免费但受限的位移
- **回溯**：时间暂停、自己位置独立改变。每个房间有回溯时长上限，是珍贵资源

### 回溯的差异化
| | Braid | 我们的回溯 |
|---|-------|-----------|
| 时间 | 倒带播放 | 暂停，只有玩家动 |
| 自己 | 跟着倒回去 | 位置独立改变 |
| 谜题本质 | 修补错误 | 两个时间维度的自己合作 |

本质是「时间分身」——回溯不是撤销工具，是解题机制。

### 场地效果（调味料，不膨胀系统）
- 高跳区域 / 重置二段跳 / 浮空平台
- 个别关卡加入巡逻敌人（利用时间暂停避开）
- 本质都是路径规划的变体，不是独立系统

### 叙事钩子
实验室 + 跨时空追捕。玩家是被追捕的实验品，每个关卡是测试房间。追捕者是**另一个时间线的自己**——最后一关揭示，解释回溯能力的来源。

### 关卡曲线
- L1-3：单机制教学（冲 → 回 → 交替）
- L4-6：机制叠加（浮空+回溯、二段跳+冲刺、高跳+敌人）
- L7-9：终极混合，精确资源管理

### 开发计划
- 现在~9月：打磨算术魔法，参加腾讯比赛
- 9月~寒假：用 Unity 做一个 3D 小项目，练熟 3C
- 寒假：组 1-2 人参赛，用练熟的框架 + 这个创意

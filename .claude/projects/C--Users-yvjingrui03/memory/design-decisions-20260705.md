## 2026-07-05 重设计决策

**Why**：颜色与运算符解绑后，经济系统和印记系统需要重新对齐。参见 [[release-plan-20260627]] 的旧经济方案。

**How to apply**：以下决策在重做实施时应用。

### 1. 卡包槽位

- 保留四个随机卡包槽位（每种颜色一个倾向包）
- 卡包整体提价 10%~20%
- 每次商店刷新，随机一个卡包获得 20% off 折扣

### 2. 颜色魔法降价

- 颜色魔法统一降价至 **6 金币**

### 3. 魔法印记上限（每张卡牌可携带的魔法效果数量）

- 运算废牌（ID 9xxx，C 品质）：上限 **1**（保持不变）
- B 品质 / C 品质牌：上限 **2**
- S 品质牌：上限 **3**
- 旧上限为 1~4，新规则降低了上限范围，与魔法产出量对齐

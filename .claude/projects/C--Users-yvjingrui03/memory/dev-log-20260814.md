## 费用增长锁定闸门（5002 的全局锁）

- `GameData.cost_growth_locked()` — 用 `has_wild_card(5002)` **所有权查询**而非状态标志：被回收后锁自动解除
- `GameData.try_add_cost_max(amount)` / `try_add_cost_base_max(amount)` — 统一入口，锁定返回 false
- 接入点共 12 处：new_play_round_start 自动增长 / 30017 还魂 / INCREASE_MAX_COST 事件 / magic_cost_expand / 王牌 2002·3001·3003·3007·4003·4004·4006·4007
- 绿色效果脚本（寄生/归尘/木/生根/生生不息/吹又生）**未接入**（内容封锁中，恢复时需补）
- 折损弃牌返还（ActiveCardContainer:317）是返还不是增长，**故意不锁**
- 事件和魔法的锁定失败有「费用上限已锁定（过期的烈酒）」tomato 提示

## InfoPage 动画状态机

**废弃的旧设计**：三个分散 flag（`_is_exiting`/`_needs_entry_anim`/`_anim_playing`）

**新设计**：五状态 `AnimState` 枚举（IDLE/ENTERING/EXITING/PLAYING_NEW_UNIT/PLAYING_QUITE_UNIT）

**统一关卡检查** `_check_unit_state()`：
- 在 `enter_page()` 的 "into" 动画之后调用
- 比较 `_current_unit_start`（当前已显示单元的起始关卡）与当前关卡
- 首次进入 → newUnit 揭幕
- 跨单元（BOSS 后）→ quiteUnit → newUnit
- 同单元返回 → 仅刷新面板 + 启用按钮

**关键守卫**：
- `exit_page()` 被 `_switch_to` 调用时，`_play_into_chain` 和 `_play_new_unit` 的 `await` 后都检查 `anim_state` 是否被 `exit_page` 改为 EXITING，若是则中止
- `_on_load_finish` 三重守卫：`now_screen == info_page and anim_state == IDLE and info_page.visible`
- `_on_desk_pressed` 守卫：`anim_state != IDLE` 时忽略（"newUnit" 动画的 `Desk:disabled` track 会误触 `pressed`）
- `_set_nav_buttons_enabled` 不再控制 Desk（Desk 由动画 track 控制）

## SelectCard 改动

- 新增 `open_event_delete(count)` 多段删卡模式：删完一张刷新网格继续，次数用尽或取消（已删 >0 时视为消费）后退出
- 删牌预览动画：播放 "delete" 而非 "right"
- 删牌执行动画：`draw_back` → 渐隐（不翻回正面），不再走 draw 流程
- 非删牌的生效动画：`draw_back` → `play`（生效特效）→ `draw`（翻回正面）
- `CardUI.show_front()/show_back()` 方法：直接控制 CardBackNode/CardFontNode 显隐
- 预览前调用 `before_card.show_front()` 确保卡面朝上

## Bug 修复

- **费用不足卡牌卡死**：`PlayField._handle_hand_to_slot` 费用检查失败后没调 `release_card_focus()`，`is_focus_locked` 残留 → 加了一行修复
- **EffectCount 不显示**：`was_zero` 路径的 fade-in tween 被结算动画中断，`modulate.a` 卡在 0。修复：每次 `_update_ui` 先重置 `modulate.a = 1.0`
- **结算分数倒扣**：`SettlementAnimator._check_all_done` 里 `info_score_target = current_score + (math_result - base_value)` 多减了一次 base_value → 改为 `current_score + math_result`
- **魔法卡重复生成**：`shop_page._on_magic_purchased` 同时调了 `buy_magic()`（触发信号 → MagicSlot 创建节点）和 `add_magic_animated()`（手动创建节点），导致两张。修复：删掉 `add_magic_animated` 调用，只靠信号驱动
- **王牌贴图路径**：`%d` → `%04d`，4 位补零匹配文件名 `0001B.png`
- **抽牌时 input_locked 未设**：`Card.fly_to_target` 加了 `input_locked = true/false` 自动锁

## 结算 + 盲盒重构

- SettlementBoard 统一管理结算流程：`SettlementInfo`（收益）+ `BlindBox`（盲盒）在一个面板里
- 盲盒交互：点击 → 开盒 → 奖励展示 → 再点击领取 → claim 动画
- 盲盒奖励类型：货币/魔法/卡包，魔法槽满时不可领取
- 数字高光功能（`GameData.number_highlight`）：默认关闭，开启后 MATH_REVEAL 结束暂停需空格确认
- 弃牌堆 + 槽位卡结算后洗回抽牌堆
- 魔法槽不再在结算时收起
- `add_magic` 拆为 `buy_magic`（商店扣钱）和 `acquire_magic`（盲盒白送）
- 商店商品购买改为原地渐隐 + 信号驱动槽位更新（不再做飞行动画）
- 王牌/魔法槽位节点直接在目标位置生成（不再从 (0,0) 飞入）
- 商品 `restore_display()` 方法：刷新商店时自动恢复 `modulate.a` 和可见性
- `fade_out()` 方法：购买时渐隐

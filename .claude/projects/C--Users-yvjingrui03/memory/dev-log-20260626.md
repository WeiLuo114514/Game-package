## 魔法系统扩展（7 个新魔法 + 参数系统）

- **30002** 底数提升+5：复用 magic_increase_base.gd，param {"amount": 5}，15$
- **50002** 额外抽牌：从「下回合多抽」改为立即 draw_cards(1)，仅 PlayField 可用
- **50003** 费用提升：描述修正为「立即使费用上限+1（可突破12费上限）」，仅 PlayField 可用
- **50005** 初始底数+3：复用 magic_global_base_bonus.gd，param {"amount": 3}，18$
- **60001-60004** 红/黄/蓝/绿色魔法：给目标卡牌附加额外颜色判定，占槽位，15$/10$
- **70001** 复制魔法：克隆目标到抽牌堆，副本重置魔法追踪/生成新UID，18$

### 系统参数
- **valid_scenes (索引[8])**：所有魔法新增场景检查参数，空数组=任意场景。50002/50003 限定 ["PlayField"]
- **商店黑名单 SHOP_MAGIC_BLACKLIST**：80001 不在商店出现，仅盲盒产出
- **效果参数字典的意义**：同一脚本+不同参数=多个魔法ID。如 10001-10005 共用 variant_type，30001/30002 共用 amount

## 颜色判定集中化重构

### 核心改动
- CardData 新增 `extra_colors: Array[String]` + `has_color(target)` 方法
- GameData 新增 `static func has_color(card_data, target)` 统一判定入口
- **50+ 处** `cd.color == "R"` 全部替换为 `GameData.has_color(cd, "R")`
- 涉及：红色效果脚本 ×8、黄色 ×2、蓝色 ×3、红色王牌 ×9、黄色王牌 ×8、蓝色王牌 ×9、PlayField ×2
- 视觉/排序/粒子仍用主色 `card_data.color`，不改造

### 设计决策
- 保留 `color` 为主色（UI/排序），新增 `extra_colors` 为额外判定（gameplay）
- 如果直接改成 Array，50+ 处引用的 UI/视觉/排序逻辑全部要重构
- 渐进式重构：不影响现有功能，只扩展新能力

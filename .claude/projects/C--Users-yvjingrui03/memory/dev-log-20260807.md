## 种子系统

- `init_game_from_deck` 开头自动播种：`set_seed(hash(Time.get_unix_time_from_system()) & 0x7FFFFFFF)`
- 用户用 `/seed N` 指定的种子每局重新应用，确保可复现
- PCG 算法新增 `rng_shuffle` / `randi` / `randf_range` 接口
- GDScript 方法遮蔽特性：GameData.gd 内部 `randi()`/`randf_range()` 自动解析为 PCG 版本
- GameData.gd 内部所有 RNG 调用（gacha/变种/UID/Boss试炼）全部迁移到种子流
- **外部 8 个文件全部接入种子**：event_page/shop_page/blind_box/PlayField/EventConfig/effect_0002/effect_0003/effect_L9009/magic_copy_card/select_card
- RoundMenu Lv1 事件/RoundMenu 路由的 `randi()` 接入
- 纯表现层（音效/相机震动/飘浮动效/喝彩词/加载提示）保持全局 RNG，故意不种子化

## 新手教程

### 流程重构（TutorialOverlay.gd）
- 旧流程：WELCOME→PLACE_FIRST→PLACE_SECOND→SETTLE→WATCH→COMPLETE
- 新流程：WELCOME→PLACE_FIRST→PLACE_SECOND→SETTLE→**DISCARD**→COMPLETE
- 删除 WATCH 步骤（结算观察），新增 DISCARD 步骤（弃牌教学）
- SETTLE 不再点击即推进，改为等 `_SettlementAnimator.all_done` 后再进 DISCARD

### AnimationPlayer 集成
- 场景中已有 `$AnimationPlayer`，编辑器需创建 5 个动画：
  - step1~step4：各步骤循环演示动画
  - RESET：停止前一个循环动画，重置视觉状态
- `_play_anim(name)` 先放 RESET（用 `_anim_chain_id` 防竞态），再放目标动画
- step3 在 `_on_settle_pressed` 中播放（非 `_enter_step`），与游戏结算动画同步

### 弃牌区教程集成
- DISCARD 步骤进入时调用 `card_container._show_fold_zone()` 强制展示弃牌区
- 拖拽权限同 PLACE_FIRST/SECOND：`tutorial_allows_drag = true`
- `_on_slot_changed` 检测到弃牌后推进到 COMPLETE

## 晚间：二合爬塔RPG 设计（2026-07-19 下半场）

### 竞品研究
- 召唤与合成：三消皮+二合魂，「任意交换+合成保留+跨关继承」
- 六款同类游戏搜索：Suika Dungeons / Battle Merge / Roguematch / Elemental Monsters / Merge & Blade / 召唤与合成2
- **核心发现**：「同型升级+异型释放」是品类空白，无一竞品实现

### 设计定稿
- 棋盘：5×7 下落式填充（向召唤与合成靠拢）
- 双轨合成：同型升级（2合1）+ 异型释放（两棋子消失触发战斗效果）
- 六元素体系：元(纯伤害)/风(棋盘加速)/火(伤害放大)/水(节奏控制)/电(护盾)/草(回复)
- 装备：局内随机掉落，死亡时折算金币，不跨局保留
- 三神经递质驱动模型：血清素(经验等级)/多巴胺(装备随机)/内啡肽(策略战斗)
- 货币：经验(无消耗端/层级锚定) + 金币(局内消耗) + 红宝石(氪金/局内增强)
- 商业模式：先 TapTap 广告验证 → 轻量内购 → 或转买断制

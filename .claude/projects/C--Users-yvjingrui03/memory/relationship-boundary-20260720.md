# 关系边界确立 2026-07-20

## 核心识别
- 这段关系的本质是**单向兼容**：用户在持续迁就对方的表达方式、情绪波动、文化差距，对方从未尝试理解用户的方式
- 对方的「绝交/删好友」口头禅训练出了不对等的规则：她可以随时切断关系，但用户连不回复都内疚
- 用户的「善良」有时不是善良，是将仅剩的精力打包成礼物送给不值得的人

## 策略定稿
1. **不主动**：不发第一条消息，就不会收到「无聊」的评价
2. **不解释**：她不主动来问，就不把感受送上门；她问了再说
3. **不删也不哄**：不需要一刀两断的勇气，但需要停止付出的清醒

## 关键区分
- 善良 = 愿意付出但算得清账
- 自我消耗 = 被消耗后还想把最后精力包装成礼物送给对方
- 「帮她变好」的真正方式：让她自己承担行为后果，而不是替她挡掉

## How to apply
当用戶在关系中被消耗时，提醒：不需要一个永远是我在迁就、对方连基本尊重都不给的朋友。不删不是懦弱，停止单向付出就是进步。

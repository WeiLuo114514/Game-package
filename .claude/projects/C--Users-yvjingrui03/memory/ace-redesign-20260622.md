2026-06-21/22 完成的全套王牌重设计工作。

## 新王牌设计（Excel: 桌面/王牌.xlsx）

三色各 9 张，品质金字塔完整（4品×3 + 3品×3 + 2品×3）：
- **红色**（1001-1009）：增益链/再触发/超载风险主题
- **黄色**（2001-2009）：经济运营/货币流转/赌博风险主题
- **蓝色**（3001-3009）：弃置转化/生死轮回主题
- **白色**（0001）：回家（洗牌抽牌）
- **关卡王牌**（9001-9022）：22 张，ID 从 3xxx 迁移到 9xxx

**Why:** 旧版王牌设计零散、缺乏叙事一致性，新版每张牌名和效果紧密扣合，三色各有独立故事线。

## ID 体系

- 0001 = 白色，1xxx = 红色，2xxx = 黄色，3xxx = 蓝色，9xxx = 关卡王牌
- 关卡王牌统一 9xxx 解决了与蓝色牌 ID 冲突

## 回收机制（已实现）

- 长按右键 1.2 秒蓄力回收，松手平滑衰减
- `WildCardUI.can_recycle` 标记控制可回收性
- 关卡王牌和 info_page 展示牌标记为不可回收
- 回收价格按品质浮动：白 2$ / 蓝 3$ / 紫 4$ / 金 6$
- 不再限制商店内回收，任何页面均可操作

**How to apply:** 新增王牌时在 WildCardUI 创建后设置 `can_recycle = false` 即可禁止回收。

## 二合爬塔RPG 开发（下午场：系统补全）

### 敌人波次链
- 5 种敌人循环出现（史莱姆→哥布林→骷髅兵→暗影法师→石像鬼），每轮 +20% HP/ATK/DEF
- 击败后 `enemy_spawned` 信号驱动 UI 全量刷新（血条/能量条/名称）

### 飘字系统
- FloatLabel.tscn（RichTextLabel 预制件）接入 UI.gd
- 上浮 80px + 0.15s 后淡出，0.8s 动画，自动 queue_free
- 敌人伤害（橙红）/玩家伤害（红）/回复（绿）/护盾获取（蓝）/新敌人名（金）/升级（金）

### 数值全面重设计
- 新伤害公式：`攻击值 = BASE_DAMAGE[等级] + ATK_RATIO[元素] × player_atk`
  - BASE_DAMAGE: [5, 10, 18, 30, 48, 72, 105, 150, 210, 290]（非线性成长）
  - ATK_RATIO: 元 0.8 > 风/火/电/草 0.5 > 水 0.4
- 除法公式替换减法：`伤害 = max(1, floor(攻击值 × 3 / (3 + DEF)))`，DEF_K=3
- 玩家 ATK 10（装备主要提供），敌人初始速度 5（每 5 动攻击一次）
- 电/草盾回系数从 ×2 砍至 ×0.4（释放）和 ×0.2（合成），降为原来的 1/5

### 经验升级系统
- EXP_TABLE: [0, 100, 150, 200, 300, 400, 550, 750, 1050, 1500]
- 击杀 EXP = 30 + wave × 5，满经验自动升级（溢出继承）
- 等级驱动棋子品质概率：Lv1-2 全 Lv1 → Lv5-6 20% Lv3 → Lv9+ 20% Lv4
- 开局填充和重力下落均走概率表

### 装备系统
- 17 件装备 × 5 稀有度（白绿蓝紫橙），每只敌人必掉一件
- 4 槽位：点击替换（旧装回收金币），Skip 回收金币
- 掉落时暂停（敌人图隐藏，EquipmentBones/Description/Skip 显示），处理完才出下一只
- 装备属性（ATK/DEF/HP/SPD）直接修正 GameManager 属性，伤害公式自动生效

### UI 标签重构
- MoneyRichTextLabel：金币(黄) + 红宝石(红)，不再显示 HP
- PlayerHPLabel：♥ HP/MaxHP [+护盾]
- PlayerSDLabel：行动值
- EXPProgressBar：经验进度条

## 设计迭代（6轮）

1. 上午：关卡王牌「自动应用」→「玩家自选启用」：初级/高级可选+50%金币，终极强制不可刷新，商店加刷新魔法
2. 下午发现核心问题：+50%金币纯正收益→玩家必然启用→选择沦为「运气检测器」
3. 改为「付费启用」→用户觉得代价过大
4. 改为「免费启用，赢了才奖励」→还是没解决无脑选的问题
5. **最终方案**：初级/高级去掉王牌，改为通关盲盒（随机魔法/货币/终极运算包）；Boss 关保留强制试炼牌（品质 1/2/3 全池，越靠后高品概率越大）+ 双倍金币
6. 关卡王牌改称「试炼」（和「王牌」「异彩」「镀层」风格统一）

## 技术改动

### 关卡系统重构
- GameData: 移除 `_level_challenges`/`enable_challenge`/`cancel_challenge`，新增 `_boss_trial_id`+`generate_boss_trial()`+`apply_boss_trial()`
- 试炼品质概率：Boss 关品质 1/2/3 全池，q3: 5%→60%, q2: 20%→50%，越靠后高品越多
- PlayField: Boss 关通关 2x 金币（`blind_type == BOSS` 判断）

### WildSlot/MagicSlot 迁至 GameWorld
- 从 RoundMenu/PlayField 独立实例 → GameWorld 共享实例
- `player_stats_changed` 信号驱动自动刷新，去掉手动 `update_from_gamedata()`
- WildSlot diff 更新：已有 ID 节点保留不动，只增删变化项
- MagicSlot Settlement 动画改为 tween（`magic_slot_tween_out()`）
- 显隐：StartMenu 隐藏，其余显示

### Godot 4.7 适配
- 3 类类型推断修复：`get_state()`/`Effect_params.get()`/`_context.get()` 返回 Variant，需要显式 `: int`/`: float`/`: CardData` 类型标注
- 修复约 40 行，涉及 `wildCardScript/` 和 `effectScript/` 目录

### 盲盒系统（BlindBox.gd）
- 1~3 次点击开盒（根据 Tier），shake→open 动画 → 展示结果 → 领取
- 奖励池：65% 魔法 / 25% 货币 / 10% 终极运算包
- `blind_box_dissolve.gdshader`：溶解+金色边缘发光

### Bug 修复
- 奖励关 L9008：ON_GAME_START 不触发（`enable_challenge` 补调 `trigger_level_wild_game_start`）
- 结算金币不刷新（`cost_to_money` 后补发信号）
- 商店重复刷新（`_needs_refresh` 标记，仅结算后刷新）
- 王牌重复显示（`add_wild_animated` 复用已有节点）
- 卡牌拖入槽位费用不足→全卡死（错误路径补 `release_card_focus`）
- 手牌位置偏上（HandField 先复位再刷新）
- 抽牌超上限（`draw_cards` 循环内加容量检查）
- 飞行中卡牌 hover 飞到 (0,0)（Card 新增 `input_locked` 标记）

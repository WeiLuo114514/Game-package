# 游戏口味

## 喜欢的（即时反馈型 ACT / FPS）
- **鬼泣5**：一天十多小时打通关，喜欢高操作密度+正反馈快的爽感
- **黑神话悟空**：玩到黄沙场景，线性关卡+叙事牵引，觉得有意思
- **泰坦陨落2**（2026-07-01 通关）：困难难度 5.7h 通关。搜点/peek/闪身枪/预瞄全进肌肉记忆，高速FPS的即时反馈完美契合口味。核心爽点：①瞄准时不同距离敌人的景深虚焦效果，模拟真实瞄具对焦，沉浸感极强，帮助专注准心；②地图编排清晰，全程无迷路；③射击手感丝滑流畅（公认优点）；④剧情三协议贯穿始终，库博与 BT-7274 的关系刻画动人。唯一遗憾爆头反馈偏弱

## 劝退的
- **艾尔登法环**：开放世界没引导，迷茫，几小时放弃（过不去区域会一直死磕直到红温下播）
- **只狼**：比法环玩得久但同样弃——地图开放不确定走没走对、画面觉得粗糙、半小时无明确反馈只觉得累。根因：消耗大量认知资源判断方向而非享受战斗
- **The Witness**（2026-08-12 购入 ¥28，30 分钟退款）：线画谜题大部分两遍能解，但正三角形/三叶符号规则悟不出；赶路时未解谜题一直挂在脑子里产生负面情绪——「解不出来还被迫赶路」的悬置感是核心痛点
- **Manifold Garden**（84 分钟，蓝色关卡完成后弃）：重力翻转+无限递归空间导致方向迷失，「哪面是地面」都要重新判断；高饱和重复色块费眼睛。智力能胜任但感官过载
- **匹诺曹的谎言**（2026-06-28 购入 ¥123.67，2026-07-01 弃坑）：第一个BOSS死无数次，「延迟满足型受苦」模式确认不适合
- 核心劝退点：延迟满足型受苦 > 即时爽感；开放世界/大世界题材完全拮抗

## 解谜游戏偏好（2026-08-12 深化）

- **顶流：Portal 系列**——1、2、双人模式全通关。本质是「线性关卡伪装成自由空间」，画面 3D 但认知负担是 2D 路线式
- **绣湖系**：场景式密集解谜，被困在一个房间所有线索触手可及，无「带着未完成任务跑地图」的认知负债
- 解谜快感来源：**收敛式问题解决**——明确规则+确定答案，可对着编程题想两天半夜爬起来验证

## 认知风格框架（2026-08-12 确立，预判游戏适配命中率高）

| 维度 | 喜欢 | 不喜欢 |
|------|------|--------|
| 空间结构 | 线性/房间制/关卡制 | 开放世界/需要自己找路 |
| 反馈密度 | 毫秒级（死→重生→再试） | 分钟级（跑图/赶路/放空） |
| 信息清晰度 | 目标明确，规则可推理 | 故意留白，需要自己悟 |
| 失败成本 | 几乎为零（秒重生/近存档点） | 丢魂/跑尸/重新赶路 |
| 智力投入 | 收敛式问题解决（编程/绣湖/Portal） | 发散式探索（大世界/多路线） |

- 核心需求不是简单，是「我知道我现在在干嘛」
- 开放世界设计前提是玩家能「愉快地放弃」绕路，而用户是未完成焦虑型（蔡格尼克效应），设计哲学与认知风格结构性冲突
- 缓解技巧：笔纸记录卡住的谜题可卸下悬置感

## 已通关/喜欢的其他

- **幽灵行者1**（EPIC 免费送）：很快通关。纯关卡制+直线推进+死了秒重生，验证框架
- **幽灵行者2**：打了一部分弃——游戏页面 Bug 打断心流 + 当时和前女友一起玩（她看操作），关系负面情感附着在游戏上捡不起来
- **泰坦陨落2**：见上

## 另一个核心类型：策略
- 从小就喜欢策略类游戏，这是喜欢卡牌游戏的根源
- 喜欢研究「技能+战术+地图」的搭配博弈，而非纯反应速度

## FPS 根基
- 从小玩 FPS 长大：从 4399 网页枪战到 3A 大作，枪法根基深厚
- 喜欢研究地图、技能搭配、战术组合，不是纯刚枪型玩家，带脑子打枪

## 联机偏好（2026-07-29 更新）
- 社交因素在游戏决策中权重大于单机恢复逻辑——有朋友一起时，策略游戏也能回蓝
- STS2 联机：转牌+华丽收场（Grand Finale）combo，联机时节目效果拉满

## 结论
- 爽点神经回路锁定在「输入→即时反馈」循环上，跨 ACT/FPS 通用
- 纯魂 like 已反复验证不适合，以后不碰了，不必再拓宽这个方向
- 三大支柱：FPS（操作快感） + 策略/卡牌（智力博弈） + ACT（连段爽感）
- 联机/社交是隐藏第四支柱，能覆盖精力管理维度的决策

## 设计者视角的觉醒（2026-07-07）
- 经过多轮魔法系统/事件牌/王牌重设计迭代后，回玩 Balatro，发现对塔罗牌、幻灵牌的理解完全不同了
- 以前觉得「没啥用的随机道具」，现在能读出每张牌的**设计意图**：为什么放在这里、和什么配合、解决什么战术问题
- 核心转变：从「玩家视角」（被动接受体验）→「设计者视角」（倒推设计决策）
- 设计密度上去了，玩家才会觉得「这游戏有东西」——这是自己做项目后才能获得的第一手体感

# 元素反应系统规则（2026-06-08 用户讲解版）

## 元素基本规律

### 附着与磨损
- 元素附着时发生**磨损**，系数 0.8：1.0U 打中 → 敌人附着 0.8U
- 反应消耗用**原数**（磨损前），反应剩余元素**直接丢弃不附着**
- 磨损是在进行附着时才进行运算，反应时用原数

### 元素留存时间
- 火水雷冰激：T = aX + b（X 为剩余量）
- 冻元素：T = sqrt(aX + b) - c
- 不同元素有不同解算数据，需保留接口/占位

### 克制关系
- 水克火、火克冰、草克水、风岩被一切克
- 被克制元素**双倍消耗**：0.8U 水 + 1.6U 火 = 正好反应
- 风岩被一切克制：0.8U 任意元素 + 1.6U 风可进行扩散

### 附着规则
- **后手元素不附着**
- **元素不叠加，只刷新到最大量**
- 不同技能有独立计时器/计数器（ICD）

### 特殊元素
- **燃元素**：草+火产生，图标同火，可与火共存，优先反应
- **冻元素**：水+冰产生（0.8水+0.8冰=1.6冻），与冰反应不同：冰/水不反应
- **激元素**：0.8草+0.8雷=0.8激，图标为草+闪电特效

## 反应系数（基准=100%）
- 扩散 120% | 超导 100% | 超载 400% | 绽放 400%
- 烈绽放 600% | 超绽放 600% | 燃烧 400%（弱草/激）
- 感电 240% | 碎冰 300%

## CD 规则
- 感电 1s 1次 | 燃烧 0.25s 1次
- 其他剧变：每 0.5s 最多 2 次伤害（超载 1 次）
- 增幅反应无 CD

## 增幅反应（融化/蒸发）
- 在增幅区获得板子（50%/100%）+ 精通区板子
- 板长 = 2.78 * [精通 / (精通 + 1400)]

## 激化反应
- 超激化板长 = 1664 + 8320 * [精通 / (精通 + 1200)]
- 蔓激化板长 = 1809 + 9045 * [精通 / (精通 + 1200)]

## 多重反应优先级
- 冻水共存：来风先扩散藏元素
- 冻冰共存：来其他元素先和冰反应
- 激雷共存：来火先超载后燃烧；来水先绽放后感电
- 雷水共存：来任何元素都先和雷反应
- 详细见用户讲解第二章

## 魔法槽位系统

- CardData 新增 `applied_magic_ids: Array[int]`，品质决定槽位数 (B=1, A=2, S=3)
- 严格槽位模型：每个目标魔法占 1 槽，满则不可再用
- 卡牌删除 (20001) 不占槽 (`consumes_slot() → false`)
- 升级魔法 (40001) 占槽（作为魔法道具使用时）
- MagicTimes VBoxContainer 显示 16×16 TextureRect，材质位于 `res://资源/Picture/MagicIcon/{magic_id}.tres`，空槽位用 NULL.tres
- DescriptionContainer 悬停时展示已用魔法（名称：描述），变种魔法只显示名称避免重复，魔法名带主题色
- 槽位满时：目标魔法走 SelectCard 立即使用，全局魔法提示"魔法已满"拒绝领取
- **Why:** 卡牌跨 Run 进收藏后无限叠加会崩平衡，槽位是硬上限

## 升级按钮独立链路

- 商店升级按钮走 `SelectCard.open_card_improve()`，不占槽位，不经过 BaseMagic
- `GameData.card_improve_count` 跟踪次数，`get_card_improve_cost()` = 5 + count × 3
- 升级魔法 (40001) 作为商品入魔法池，固定价格 7
- **Why:** 升级是卡牌自身形态变化，非外部魔法强化；按钮和魔法是两条独立途径

## LevelPanel + InfoPage 动画

- InfoPage 三个 LevelPanel 对应单元内 3 关，`setup(level_num)` 根据盲注类型切换显示（普通/高级→分数，试炼→Card）
- 三种入场场景：新游戏→newUnit，Boss 完成→quiteUnit→newUnit，普通关卡→Complete 显示
- `_needs_entry_anim` 标志 + `load_finish` 信号触发，解决 shop 先显示时动画时机问题
- Complete 材质直接用 show/hide，不用 tween
- **Why:** `_on_visibility_changed` 时可能 shop 覆盖 InfoPage，动画需延迟到玩家真正看见时

## 弃牌消耗系统

- `stat.discard_free = {val, next}`，根据 deck_id 设置（红1/黄2/蓝3）
- 第 N 次弃牌费用 = max(0, N - 免费额度)，免费额度内 0 费
- 只有拖拽到 FoldZone 的主动弃牌计数，结算收牌和手牌软上限不计入
- FoldZone 上显示 CostToFold 标签（免费 / -X费用）
- 蒸腾作用效果改为 `discard_free.next += free_extra`
- **Why:** 主动/被动弃牌分开统计，避免结算流程干扰跨回合计数

## OPcard 输入锁

- `fly_to_target(lock_input=false)` — 只有抽牌到手牌区传 true
- kill 旧 tween 时先清理 input_locked 残留，再根据新参数决定
- **Why:** 旧 tween 被 kill 时 finished 永不触发，锁状态卡死 → 卡牌永久不可交互

## 信号泄漏

- RoundMenu 的 `_on_select_card_cancelled` / `_on_immediate_use_cancelled` 必须断开 `completed` handler
- shop_page 的 `_on_upgrade_cancelled` 同理
- `_on_card_improve_pressed` 连接前遍历断开所有已有连接
- **Why:** CONNECT_ONE_SHOT 只在信号触发时自动断，cancel 不会触发 completed → handler 残留 → 后续流程误触发

# 开发日志 2026-07-12/13

## 效果范围预览系统（全量实装）

在 BaseEffect 新增 `get_affected_indices(slot_cards, self_index) → Dictionary` 虚方法，返回 `{slot_index: {color, rng}}`。

- **红牌 17/18** 已实装（蒸腾作用无槽位目标省略），燃尽/燃点两段式（达标实色否则浅色），爆燃始终浅色
- **黄牌 20/24** 已实装（春风/麦浪/金色合唱团无槽位目标，投资为手牌触发器），14 张 RNG 牌统一 `{_index, rng:true}`
- **蓝牌 6/17** 已实装（11 张 ON_DISCARD/ON_DRAW 触发器类无需高亮）
- **pure_numeric** 已实装（红番二等纯数值牌）

### 设计决策
- 条件触发效果（燃尽、燃点、乌合之众等）：条件满足→实色，不满足→浅色/空字典
- RNG 效果（押注、千术、老虎机等）：统一浅色自己，不假装能预判
- 弃牌/手牌触发器（三十三小队、占卜等）：默认空字典，不显示槽位高亮
- 半确定效果（播种）：左侧确定→实色，右侧 RNG→浅色
- 颜色映射：确定目标 alpha=1.0，RNG 目标 alpha=0.7

### UI 层
- Card._on_mouse_entered → 0.2s SceneTreeTimer → ActiveCardContainer.show_effect_preview()
- Card._state_drag_enter → _cancel_hover_preview() 立即清除效果高亮
- ActiveCardContainer._effect_highlight_map 管理多槽位高亮，_update_slot_guide_highlights() 统一渲染

## 商店重构

**删除**：GoodsEvent（事件商品）+ CardImprove（升级卡牌按钮）

**新增**：特价区（Panel1，一个 GoodsPack 槽位），固定 8 折（ON_SALE_DISCOUNT=0.8），随机从 8 种包型中抽取

**常规区**（Panel2，3 个 GoodsPack）：不再有随机折扣

**颜色偏好按钮**移至 ShopBackground 下直接子节点，文本格式："卡包颜色偏好\n红"（轮换：红→黄→蓝→绿→全部）

商店从 10 项 → 8 项，认知负荷降低。升级只能通过升级魔法（40001），稀缺感提升。

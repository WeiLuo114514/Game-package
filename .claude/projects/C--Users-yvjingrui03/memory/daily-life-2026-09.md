## 求职·畅游 offer（9/6 收到）

**待遇明细（与 HR 终面 16-18k 口径有 base 差额，疑为定级机制）：**
- 月 base **15,000 税前**（入职 P0，定级后 P4~P6，每年两次晋升通常带调薪）
- 年薪 **14~16 薪**（每年两次测评定年终月数）
- 七险一金**全额缴纳**，公积金按 **12% 最高比例**
- 餐补 400/月；试用期 6 个月**全额**，前 3 个月不纳入绩效（新手保护）
- 实习选项：170/天 + 1000/月住房补贴（按出勤）
- 合同 3 年（标准）；违约金：签后拒 offer 付 **5000**（劳动法第 25 条下效力弱，主要心理/HR圈约束）

**定价事实（9/6 澄清，修正早前「横向对比/非唯一候选人」顾虑）**：
- BOSS 两条 JD：一条 15~18k、一条 11~20k；**给 15k = JD 低档**
- HR 口径：**按面试结果定薪，无横向对比**（早前 8/20 记的「非唯一候选人/内部横向」已被澄清为不成立）
- base 15k 是否 P0/定级前、转正定级落到 15-18k 区间哪档 —— 待签前一句话澄清（设预期，不砍价）
- HR 表示可先考虑，**约 2-3 周内答复、别太久**
- 区位：石景山区物价 < 上海/杭州 → **购买力 ≈ 顶尖大厂**；北京离河北家近（火车 1-2h、票 5-60 元），亲戚子女多在京津

**测算（北京全额缴）**：月到手 ≈1.12-1.13 万；公积金个人+公司 ≈4.3 万/年入账；工资税前总包 21~24 万；到手现金+公积金 ≈20~23 万/首年。

**决策（9/6，倾向签）**：
- 无「来了立刻毁约」的 dream 公司（网易/米哈游/腾讯各有利弊）→ 秋招 option 价值≈0；DS(C端) 也推荐签
- 违约金 5000 只作用于**入职前拒 offer**；入职后离职提前 30 天即可、无违约金 → 签 = 低承诺高地板，但**当最终决定签**，不当垫脚石
- 职业哲学（详见 [[user-prefs]]）：策划=工作面对 KPI；艺术走独立游戏通道（Arithmetrick）——两者互喂，分不到卡牌项目不构成 con
- **执行**：口头回 HR「倾向接受」捂热 offer → 正式三方/协议手续放 **9/15 腾讯比赛后一周**；2-3 周窗口给比赛冲刺+论文+gut check，不再撒秋招网

### 入职时间线落定（9/8）
- 大四无任何课程；学校实习任务已用「盖章」完成（无真实习硬性要求）；双证 2027 年 7 月前必到
- **正式入职 = 2027-07-06（周二，安和直接定）**
- 实习：公司**不要求**；若要适应可答辩后预留 ~2 个月；想好提前告知 HR（暂不发实习 offer）
- 用户选择：**答辩后实习 ~2-3 个月**再入职（与 HR「~2 个月」基本一致）
- **春季待核**：2027「开学答辩」是开题/中期还是正式答辩、落几月——决定实习窗口能否塞进 7/6 前（答辩需 ~4-5 月结束才有 ~2 个月余量）
- 求职主线至此收官：offer 锁死 + 7/6 入职定；下一节点 9/15 腾讯比赛

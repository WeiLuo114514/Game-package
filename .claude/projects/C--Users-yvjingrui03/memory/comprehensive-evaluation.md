# 综合素质测评（南昌师范学院 数学与信息科学学院）

测评以**学年**为单元，每年重来一次。细则为《数学与信息科学学院学生综合素质测评实施细则（2023年12月修订）》，自 2024-09-01 起实施。

## 权重

综合测评总分 = 德育×35% + **智育×35%** + 体育×10% + 美育×10% + 劳育×10%

## 智育测评分

智育测评分 = 加权平均分 + 奖励分 − 处罚分

- 加权平均分 = Σ(各科分数×各科学分) / Σ各科学分
- 只算上年已修全部课程，**不含公共选修课**
- 等级制换算：分数 = 学分绩点×10 + 50（优秀 95 / 良好 85 / 中等 75 / 及格 65 / 不及格 50）
- 结果保留 2 位小数四舍五入
- **智育没有上限**（德育封顶 100），奖励分全额线性计入 → 智育是性价比最高的刷分模块

## 竞赛加分能不能认（关键坑）

智育奖励分六类里，竞赛只能进这两类，且定义松紧不同：

| 类别 | 原文限制 | 结论 |
|---|---|---|
| 【科技创新活动类】 | 「大学生科技创新活动指**校级以上政府部门主办**的相关竞赛」（互联网+/挑战杯/数模等） | **封闭式定义**——商业公司自办赛基本不认 |
| 【学科竞赛类】 | 「与专业学习相关的学科竞赛（如英语口语）」 | 含糊，有裁量空间，交学工办认定 |

- 学科竞赛类分值：国家级 18/12/10/8，省级 12/10/8/6，市厅级 10/8/6/4，校级 6/4/2/1，院级 3/2/1/0.5（对应一等/二等/三等/其他）
- **比赛未获奖的，按该级别「其他」类再减半**
- **排名第一按原分值，其他成员减半**
- 必须提供获奖公示文件或盖举办单位公章的证书；国家级项目**必须**报学工办审核
- 「国家级」在这些细则里通常指国家部委/教育部认可竞赛目录，公司自办赛按国家级报大概率被退回

## 用户基线

- **2025-2026 学年智育加权平均分 = 85.88**（9 门课，12.5 学分，1073.5/12.5），无奖励分无处罚分
- 学校系统另有一个「平均成绩」字段 ≠ 本公式结果：2025-2026 学年该系统给的是 88.11，反推为**不加权**且把「良好」按 **89** 分算的口径，两套不同，别混用

## 用户立场：综测/奖学金已不再是目标（2026-09 明确表态）

原话要点：大一大二**已连拿两年三好学生 + 三等奖学金**；整个大三刻意不刷综测分，全部投入**游戏领域深耕**为求职服务；2026 秋招**已拿到 offer（税前月薪 15k）**；再拿三好也没用了，奖学金那点钱也不差。

**Why:** 目标是游戏行业求职，作品集（Arithmetrick 上架 Steam）的权重远高于校内荣誉；offer 已落地，边际收益趋零。
**How to apply:** 不要再建议「去争综测分/刷奖学金/报竞赛冲三好」这类校内荣誉路线。给建议时默认以**作品集质量、行业技能、职业发展**为优先级。除非用户自己重新提起，否则不要主动把它当成一个待办。

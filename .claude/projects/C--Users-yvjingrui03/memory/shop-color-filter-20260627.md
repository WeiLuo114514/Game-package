## 商店颜色过滤

**What**：商店右上角添加颜色按钮，玩家点击循环切换颜色（红→黄→蓝→绿→全部），影响卡包/商品中该颜色卡牌的出现权重。

**Why**：玩家在某局中通常聚焦 1-2 个颜色流派，刷出一堆无关颜色的牌是负体验。给玩家一个软引导（而非硬过滤）来增加目标颜色的出现概率。

**How to apply**：按钮切换时修改 `color_weight_bias` 参数，商店刷新时目标颜色权重 ×1.5~2.0，其他颜色仍可出现（只是概率降低）。不做硬锁定，保持策略灵活性。

### 设计决策

- **权重而非硬过滤**：如果红锁定后完全不刷其他颜色，玩家会错失跨色联动机会（如绿蓝联动）。权重倾斜足够引导但不限制
- **全部色仍为默认**：每次进商店默认显示「全部」，玩家主动切颜色
- **绿色也加入**：虽然绿色未实装，但按钮预留四个颜色位置

### 按钮资源
- 路径：`res://资源/texture/ColorButtonStyles/`
- 每种颜色一个按钮样式（theme_override_styles/normal）
- 按钮文字显示当前选中颜色名

### 与其他系统的关系
- 商店黑名单（`SHOP_MAGIC_BLACKLIST`）是另一套机制，互不影响
- 不改变卡包的基础概率分布，只叠加权重修正

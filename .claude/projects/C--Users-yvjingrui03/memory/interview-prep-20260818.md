## 三面复盘深化教训（面试可复用）
1. **"最喜欢的游戏"题要落机制层**：面试官问"最喜欢哪款/品类/能否复刻/亮点风险"是竞品拆解测试。答"品类共识"（好玩/能探索/每次新开始）会被判"太宏观"。正确答法：这个游戏独有的 1-2 个机制 + 一个例子。例：Balatro=5 槽位 modifier 极简构建面 + 每回合买/刷/跳过单决策。
2. **面试官低头/沉默=他内部处理，不是你的话轮**：抢话输出的是防御性低质内容（随手抓的素材放错位置）。判断话轮：他抬头/眼神给你/问句收尾才是开口时机；不确定用"您想让我展开还是往下一个"。
3. **别用"学习能力强/上手快"空包弹**：无证据的自我声称等于没说，且答非所问（他质疑设计力，你回执行力）。
4. **策划案文档=没打出去的牌**：三面面试官反复说"回归设计产出文档"，用户桌面躺着三份完整策划案（立项案/系统案/数值案）却没掏。面试官一提文档就甩文件夹。
5. **"重执行轻设计"是证据链覆盖问题**：执行层有实据（代码/系统/数据/Steam 上架），设计层只有叙事（没记录"为什么这么设计/对比过哪些方案/怎么判断好坏"）。翻案方法=展示设计决策记录。
6. **面试官"扣结论"式风格**：不引导、不追问细节、直接定性——可能是总监式讲话习惯/不擅长面校招生，不是用户价值问题。复试预期可能同风格，用"去展示不是去自证"心态进。

## STS2 面试答案（8/18 备用）
**Why 选它**：玩得久 / 正在做 DBG=研究品类标杆 / 新发售显前沿 / 测过联机多一个素材。
**亮点**：①单局自洽即兴决策（三选一+遗物+事件组装，构筑长在战斗里）②地图路径=战斗外构筑决策（精英/商店/休息点预判）③敌人设计教你怎么玩（精英/Boss 有解题思路，逼你调整构筑）。
**复刻抓手**："单局三选一构筑 + 地图预判 + 敌人解题式设计"核心循环。难点=组合空间平衡爆炸（几百牌×上百遗物）。
**风险**：①组合平衡海量 ②通关即弃需无尽/高难/解锁维持 ③"什么牌该拿"隐藏复杂度，新手不知所措。
**收尾钩子**："我做 Arithmetrick 参考 STS 单局决策压力设计，用数学运算降理解门槛，保留决策深度。"

# 畅游复试复盘（2026-08-18）

## 面试概况
- 时间：2026-08-18 上午约 10:20 开始，73 分钟（面试官迟到约 20 分钟）
- 面试官：**湛蕾**（业务深面，教学式风格；用户判断疑似中台/平台方向，起初不确定会往哪带）
- 岗位：游戏策划培训生（系统/数值/战斗三岗轮岗）
- 状态：业务面顺利收尾，结果由 HR 统一同步。用户体感"稳了"

## 加分项（AI纪要确认）
- 开局亮 Steam 上架产品=落地执行力
- 立项逻辑：市面缺"易上手 DBG"→切高门槛痛点→轻量化空白+微创新
- 数值实操：蒙特卡洛验证、关卡分数曲线、逆向推导《原神》元素反应（假设-验证闭环）
- 执行力兑现：针对一面"策划案不规范"反馈补了数值总表+立项案全套文档

## 主失分点：策划案"为什么"层缺失
面试官反复纠正：
- 策划案首要写"为什么做"而非"怎么做"；先搭骨架(大纲)再填血肉
- 区分设计目的/系统框架/数值实现三层；系统策划别伸太长去细化数值
- 货币文档把货币本体设计写丢=本末倒置
- 结果：写策划案时全铺实现细节，缺设计逻辑与取舍

## 关键洞察（用户补充）
- 用户口头讲故事环节**刻意**讲了设计决策过程（颜色解绑故事、绿色一天三版故事）——说明**设计思维在，缺的是"把口头为什么翻译进文档"的载体转换能力**
- "重执行轻设计"真面目：不是不会想为什么，是**文档载体只装"怎么做"，没装"为什么"**
- 三面扣结论无解法 vs 今天湛蕾教学式给出解法=真实的短板信号+可培养信号

## 成长证据（用户补充）
- 面试官讲完策划案缺失后，用户**等她说完成接**（没抢话），坦诚承认：没做过多人群项目（solo/小项目经验）、不清楚方向所以答得混乱
- 归因漂亮：把"答得混乱"归到经验/信息层面而非能力——诚实不甩锅，又不自钉"不行"，让面试官指导有的放矢
- 对比三面：被定性时抢话自辩 → 今天诚实承认+清晰归因。同一类场景两种反应，面试官能感知成长
- 技术内容自我觉察：起初以为会被往技术策划带，部分回答带技术内容，后见方向仍为数值/系统/战斗三岗即收住、不再提技术策划。判断：技术是真实力（一人全栈）非扣分项，今天被打的是策划案缺设计逻辑而非懂技术；收住技术策划正确（岗位是系统/数值/战斗轮岗，提技术策划会模糊定位）。读面试官信号调整方向=策划基本功

## 正面信号
- 面试官花大量时间教学=培养意愿
- 结尾双向沟通：默认"进去先干自己尝试"、定岗建议（优先系统/战斗数值）、"按成就感判断上限"——话里默认用户会入职

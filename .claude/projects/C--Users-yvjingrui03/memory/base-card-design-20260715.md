# 底牌系统设计（2026-07-15）

## 底牌定位

全局唯一，开局选择（StartMenu 套牌选择时同步选择），和王牌槽位/魔法槽位并列展示。竖直长矩形造型，与魔法卡面统一。

三个功能：
1. **身份归属**：每局行动前获得身份倾向，影响构筑策略
2. **初始底数载体**：解释不同套牌初始底数差异的理由
3. **主动技能**：全局唯一主动技能，有各自冷却计数条件

## 设计原则

- 替换收益不高是刻意的——玩家决定替换应该是「新底牌更好」，而非旧底牌的替换收益太强
- 软引导不硬锁定——冷却条件有颜色倾向但不强制（如「结算 9 张红色运算牌」）
- 冷却数字写在底牌 UI 上，初始底数值在当前 PlayInfo 已有显示，不重复

## 替换机制

替换时旧底牌对新底牌产生一次性效果（如底数加成、额外效果），旧底牌消失。

## UI 规划

- 和王牌槽位/魔法槽位并列，空间足够
- 竖直长矩形，造型与魔法卡面统一
- 冷却进度：进度条做边框，从暗到亮渐变（红=火焰纹、黄=星芒纹、蓝=水波纹、绿=藤蔓纹），冷却完成时边框发光
- 技能图标在牌面中心
- 冷却数字直接写在底牌上

## 红色底牌 ×3

### 1. 不灭的烈阳

| 属性 | 值 |
|------|------|
| 初始底数 | 10 |
| 冷却 | 2 个关卡 |
| 替换收益 | 替换底牌的底数 + 本牌底数的 30% |

**效果**：将消耗堆的所有运算牌洗入抽牌堆，并将已获得分数 ×180%。每从消耗堆洗入一张牌到抽牌堆，额外 ×20%。

分数公式：加法叠加 `(180 + N×20)%`。

**节奏**：前期消耗堆少时收益有限，后期或 Boss 关消耗堆攒起来后一招翻盘。自我平衡的增长曲线。

**额外约束**（待实现）：洗回的消耗牌本回合不可抽取，防止 combo 过度。

### 2. 熔火意志

| 属性 | 值 |
|------|------|
| 初始底数 | 12 |
| 冷却 | 结算 9 张红色运算牌 |
| 替换收益 | 替换底牌的效果加上「随机丢弃一张手牌，并抽取一张牌」 |

**效果**：将此时所有的手牌洗入弃牌堆，并抽取等量的手牌。

**节奏**：手牌全换，节奏调节型。冷却条件「结算 9 张红牌」是行为冷却，红牌多的卡组滚得快，形成软倾向而非硬锁。

### 3. 助燃剂

| 属性 | 值 |
|------|------|
| 初始底数 | 9 |
| 冷却 | 8 张红色运算牌的效果生效 |
| 替换收益 | 替换底牌的效果加上「为随机一张手牌的增益计数 +2」 |

**效果**：选择生效区的一张牌，将其底数 +1，但本次增益效果被视为生效了三次。

**节奏**：微量增益通过「加速计数」放大——+1 底数但 effect_count +3，触发依赖计数的效果链（燃尽等）。选择目标需要槽位级别的 UI 交互（参考王牌 ON_WILD_ACTIVATE）。

## 三种冷却机制对比

| 底牌 | 冷却类型 | 模式 |
|------|------|------|
| 不灭的烈阳 | 关卡冷却 | 每关结束 -1，约 6-9 回合/冷却 |
| 熔火意志 | 行为冷却（结算） | 红牌结算计数，红牌多时约 2-3 回合 |
| 助燃剂 | 行为冷却（效果触发） | 红牌效果触发计数，约 2-3 回合 |

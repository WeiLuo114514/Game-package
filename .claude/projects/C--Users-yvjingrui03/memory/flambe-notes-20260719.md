# Flambé 体验笔记

## 核心循环
- **二合→建造驱动**：局内合成售卖产出金币→建造餐厅。订单只是赚钱手段，目的指向建造/重建繁荣。
- 局内以天数作为关卡分隔，完成一关所有关卡→完成一天
- 局外以建筑物重建繁荣为一个单元，全部建筑完成→进入下一场景
- 开棋盘是区域锁：达到某天数时解锁一个区域的封印棋子（可被激活）

## 加工系统
- 工具棋子可加工食物到客人需要的形态（如玉米剥粒）
- 加工棋子本身有冷却/等待时间（几秒到二十分钟之间）
- 加速道具可跳过加工等待，消耗量与跳过的时间长度正相关
- 加速道具多渠资产出：各类活动、礼盒、图鉴收集、戳破双倍泡泡等

## 节奏特点
- **先慢后快**：前期主要是生产棋子的冷却压力；后期活动免冷却操作，体力迅速见底
- 过了前期后，几乎每个客人完成订单时奖励「额外使用次数」道具→变相鼓励资源规划
- 资源规划合理时，恰好刚好可以完成所有订单

## 付费
- 小额高频：1.99 / 3.99 / 19.99 刀，和梦幻消除战类似
- 弹窗触发点相对克制：没体力时/进游戏时/完成建造时（vs 梦幻消除战 3-4-5-7 级弹窗链）
- 星期天有额外 1.99 刀礼包
- 通行证免费版都是垃圾，付费版给很多体力
- 双倍产出花钻石保留

## 活动
- 活动很多，类型丰富（和梦幻消除战形成对比）
- Clash of Cakes：类 PVP 蛋糕对决，比谁订单做得快（疑似真联网 PVP）
- 新建造完成时：每 7-8 个建筑→宝箱（50 体力 + 5 红宝石）
- 加速时钟道具可大幅缩减所有生产棋子冷却

## 建造经济
- 重建所需金币以场景为单位量级提升，场景内无明显规律
- 所需金币有波动，不总是递增

## 资源
- 体力（2 分钟回 1）、金币、红宝石 → 和梦幻消除战一致
- 额外：加速道具（用于加工棋子和生产棋子）

## 感官
- 收集道具物品有轻微震动反馈

## 解锁节点

## vs 梦幻消除战 关键差异
| 维度 | 梦幻消除战 | Flambé |
|------|:--:|:--:|
| 核心循环 | 二合→订单驱动 | 二合→建造驱动 |
| 操作节奏 | 从头到尾操作密集型 | 先冷却等待→后体力瓶颈 |
| 压力点 | 体力+格子双压力 | 体力+冷却+加速道具，更分散 |
| 付费密度 | 3-4-5-7 级弹窗链 | 克制触发，但每次体力耗尽/进游戏弹 |
| 加工深度 | 合成链短 | 工具棋子+多段加工链 |
| 目标感 | 尽快完成订单 | 长期建造目标更明确 |

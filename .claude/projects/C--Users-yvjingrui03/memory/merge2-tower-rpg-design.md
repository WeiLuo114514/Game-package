# 二合+爬塔RPG

> 创意来源：畅游笔试第三题「二合+X 新游戏设计」，但设计热情超出了笔试范畴
> 参考：幸运猎人（鱼尾，Roguelike+棋盘战斗）、梦幻消除战、Flambé

## 核心 pivot

把传统二合的「生产→合成→提交订单」替换为「生产→合成=攻击→击杀→爬塔」：

| 传统二合 | 本设计 |
|----------|--------|
| 体力是核心限制（等 or 付费） | 敌人倒计时是核心限制（时间压力） |
| 合成产出物→等订单→提交 | 合成=攻击动作，合并瞬间造成伤害 |
| 棋盘爆满惩罚=被迫卖棋子 | 棋盘空间=战术布局选择 |
| 爽感来自「攒够了交任务」 | 爽感来自「combo 连击打爆敌人」 |

## 系统规格

### 棋盘与布局
- 7×9 棋盘（下）+ 人物攻击动作展示（上）
- 六元素体系：元/风/火/水/草/电
- 生产源棋子 → 基础元素棋子 → 合成升级/跨元素 combo

### 玩家参数
- HP、护盾值、经验值（永久保留）
- 每次生产/合成消耗敌人倒计时（本质回合制）

### 敌人参数
- HP、行动倒计时（进度条展示）
- 行动时：攻击 or 棋盘负面效果（封印棋子/毒棋子/摧毁棋子）

### 爬塔循环
- 击败敌人 → 累计经验值 → 永久提升战力+起始层数
- HP 归零 → 失败重来 → 经验值保留（roguelite 轻度永久成长）

### 合成链（待定）
- 同元素合并 = 强化版（数值翻倍）
- 跨元素合并 = combo 技能（利用元素反应设计经验）

## 开发计划

绿色流派：「- 费用操作」—— 以 `-` 运算符为主体，**费用**为核心操作维度。核心循环：留费（克制）→ 烧费（爆发）→ 产费（再生）。不引入任何新系统，全部操作基于已有费用机制。

**Why**：2026-06-28 用户设计定稿，历经三版迭代（手牌位置 → 蔓系统 → 费用操作）。借鉴杀戮尖塔2 储君辉星、怪物火车 Purge/Reform、Inscryption 牺牲，最终落实为「零新系统」的最高完成度版本。

**权威数据源**：桌面 `卡牌.xlsx` → 绿色卡牌页（ID 40001-40015，含设计讲解列）

## 设计哲学

绿色与其他三色最大的区别：**操作的维度是费用本身，而非数字/运算符。**

| 流派 | 关注维度 | 核心操作 |
|------|---------|---------|
| 红色 | 数字（底数） | × 链爆发 |
| 黄色 | 时间（永久成长） | + 累积 |
| 蓝色 | 符号（运算符） | 弃置转化 |
| 绿色 | 规则（费用） | 留费/烧费/产费 |

绿色玩家不需要学新术语。费用就在屏幕上，剩余费用一目了然。

## 深度层分析

**入门层（2 层认知）**：留费→烧费→修复减法。初始牌教会基本循环。

**精通层（5 层认知）**：
1. 森·木枯荣循环（40012→40013→40012）
2. 寄生时机（先放牌降费→再弃置寄生翻倍）
3. 春泥续命（用其他牌增益强制触发）
4. 发芽回收（结算后收走已完成的牌换费）
5. 吹又生跨色联动（触发蓝牌弃置链 + 大量产费）

**隐藏层**：[临时]·木 可跨关卡保存，魔法可覆盖 [临时] 标记使其转正。

## 绿色内部自平衡

- 绝大多数绿色牌为 **0~1 费**，防止费用生成套娃失控
- 40011 发芽吃低费牌收益有限，逼迫玩家考虑跨色目标
- 40008 万物竞发需要先转化运算符再使用，不能无脑烧费

## 与蓝色联动

- 40015 吹又生：Lv2 丢弃所有手牌，同时触发所有蓝牌弃置效果 + 大量产费
- 40010 生根：连锁弃置随机牌，配合蓝牌弃置触发器
- 40011 发芽：可控弃置（送入弃牌堆而非移除），蓝牌可从中受益

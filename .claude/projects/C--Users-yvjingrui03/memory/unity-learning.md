用户当前使用 Godot 4.6 开发卡牌游戏，同时计划在后续 3D 项目中转用 Unity/团结引擎。

**Why**：Godot 3D 能力不够满意，Unreal 蓝图对 AI 协作不友好，Unity C# 文本脚本模式最适合与 AI 结对编程。

**How to apply**：
- 卡牌项目（「简单的算术魔法」）继续用 Godot 4.6，不切换引擎
- 3D 新项目再启动 Unity，届时参考桌面 `Godot到Unity概念对照.md`
- 团结引擎（Unity 2022 LTS 中国特化版）核心 API 与国际版一致，英文教程适用

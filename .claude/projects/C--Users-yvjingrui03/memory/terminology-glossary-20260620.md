## 名词释义表

用户与 AI 协作梳理，作为代码、UI、设计文档的统一命名标准。

### 卡牌体系

| 中文 | 英文 | 释义 |
|---|---|---|
| 运算卡 | Operation Card | 可放入槽位参与结算的卡牌（日常简称「卡牌」） |
| 王牌 | Wild Card | 不放入槽位，结算时根据条件被动触发增益的特殊卡 |
| 异彩 | Luster | 运算卡的特殊表面处理：炫彩/错版/闪光/限定/折损 |
| 镀层 | Plating | 王牌的特殊强化系统（待实现） |
| 魔法 | Magic | 一次性卡牌修改道具（异彩赋予、删除、升级等） |
| 品质 | Quality | 稀有度：普通(B) → 稀有(A) → 史诗(S)，王牌为 X 品质 |
| 等级 | Level | 卡牌升级次数，提升效果参数 |
| 颜色/流派 | Color | 红色(R) / 黄色(Y) / 蓝色(B) / 通用(W) |
| 套牌 | Deck | 玩家携带的卡牌集合，决定抽牌池 |

### 场上区域

| 中文 | 英文 | 释义 |
|---|---|---|
| 槽位 / 牌位 | Slot | 场上 1–5 号位置，卡牌放入后参与结算 |
| 手牌区 | Hand | 当前持有、可拖入槽位的卡牌 |
| 抽牌堆 | Draw Pile | 未抽取的卡牌堆 |
| 弃牌堆 | Discard Pile | 使用/弃置后进入，抽空时洗入抽牌堆 |

### 游戏流程

| 中文 | 英文 | 释义 |
|---|---|---|
| 本局 | Run | 从选择初始套牌到游戏结束的完整过程 |
| 本关 | Stage | 一个关卡内的流程 |
| 结算 | Settlement | 回合末的顺序处理：CARD_EFFECT → WILD_CARD → MATH → CLEANUP |
| 回合 | Round | 一次完整的 抽牌→放牌→结算→清理 |
| 生效 | Trigger | 卡牌或王牌的条件满足并执行 |

### 关卡难度

| 中文 | 英文 | 释义 |
|---|---|---|
| 初级挑战 | Basic Challenge | 对应 Level 1 |
| 高级挑战 | Advanced Challenge | 对应 Level 2 |
| 终极挑战 | Ultimate Challenge | 对应 Level 3 |

### 操作动词

| 中文 | 英文 | 释义 |
|---|---|---|
| 弃置 | Discard | 将手牌移入弃牌堆 |
| 洗牌 | Shuffle | 弃牌堆随机排序后移入抽牌堆 |
| 置顶 | To Top | 固定到抽牌堆顶部，下次优先抽出 |
| 回手 | Return to Hand | 从槽位/弃牌堆移回手牌区 |
| 插队 | Queue-jump | 在结算队列中插入额外条目 |

### 经济

| 中文 | 英文 | 释义 |
|---|---|---|
| 货币 ($) | Money | 局内货币，用于购买魔法/卡包 |
| 卡包 | Card Pack | 获得新卡牌的抽取道具，按颜色和等级分 6 种 |

**Why**：统一开发/设计讨论中的术语，避免变种/异彩/镀层/Wild Card 等名词混用。所有新增 UI 文案、代码注释、设计文档均应以本表为准。

**How to apply**：`tr()` 中的 key 使用中文列的值，英文翻译对应 English 列。新增术语时先更新本表再同步 translations.csv。
